# Закупки — Объекты метаданных

> **Раздел:** 06_Закупки
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, SCloud, Ассистент

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Номенклатура поставщиков** | Сопоставление артикулов поставщика с вашей номенклатурой. |
| **Номера ГТД** | Справочник таможенных деклараций (для импорта). |
| **Классификатор ТН ВЭД** | Коды товаров для расчета пошлин (для импорта). |
| **Причины отмены заказов** | Обоснование отмены строк в заказе поставщику. |

## Документы

| Документ | Назначение |
|---|---|
| **Расчет потребностей** | Обработка для формирования рекомендаций по закупкам. |
| **Заказ поставщику** | Планирование закупки. Не создает долга и остатков. |
| **Приходный ордер** | Физическая приемка товара на склад (ордерная схема). |
| **Приходная накладная** | Финансовое оприходование (создает остатки и долг). |
| **Счет на оплату (полученный)** | Регистрация счета от поставщика для оплаты. |
| **Дополнительные расходы** | Включение доставки/услуг в себестоимость товара. |
| **Расходы при импорте** | Включение таможенных пошлин/НДС в себестоимость. |
| **Акт о расхождениях** | Претензия поставщику (ТОРГ-2). Не меняет учет. |
| **Корректировка поступления** | Изменение цены/количества уже принятого товара. |
| **Расходная накладная (Возврат поставщику)** | Возврат товара поставщику (уменьшает остатки и долг). |

## Регистры

| Регистр | Назначение |
|---|---|
| **Заказы поставщикам** | Потребность в товарах (что и сколько заказано). |
| **Запасы** | Количество и сумма оприходованного товара. |
| **Запасы к поступлению на склады** | Товар, принятый по ордеру, но не оформленный накладной. |
| **Расчеты с поставщиками** | Задолженность перед поставщиками (долги). |
| **Оплата счетов и заказов** | Связка счетов, заказов и оплат. |

## Связи между объектами
*   `Заказ поставщику` -> является основанием для `Приходной накладной` и `Счета на оплату`.
*   `Приходный ордер` -> является основанием для `Приходной накладной` (при ордерной схеме).
*   `Приходная накладная` -> является основанием для `Дополнительных расходов`, `Возврата поставщику` и `Корректировки поступления`.
*   `Счет на оплату (полученный)` -> связывает `Заказ` и фактический платеж (`Расход со счета`).
