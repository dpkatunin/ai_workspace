# 07_Продажи. Объекты (Метаданные)

## Справочники (Catalogs)
| Имя объекта | Роль в продажах | Важные реквизиты/Особенности |
| :--- | :--- | :--- |
| **Контрагенты** | Клиенты | Вкладка «Взаиморасчеты»: флажок «По счетам» (включает учет оплаты счетов). |
| **Договоры** | Условия работы | Вид договора: «С покупателем», «С комиссионером» (для отчетов комиссии). |
| **Номенклатура** | Товары и услуги | Вид «Услуга» для доставки/комиссии. Вкладка «Прайс-лист» (флажок «Не включать в прайс»). |
| **Виды цен** | Ценообразование | Тип: Статический, Динамический (процент), Динамический (формула). Требует флажка «Авторасчет». |
| **Условия предоставления скидок** | Автоскидки | 13 видов (разовый объем, комплект, накопленный объем по карте и др.). |
| **Виды автоматических скидок** | Автоскидки | Способ: Процент, Сумма, Подарок, Вид цен, Сообщение. Флажок «Это правило начисления бонусов». |
| **Бонусные программы** | Лояльность | Курс балла, % ограничения оплаты, срок сгорания. |
| **Дисконтные карты (Виды карт)** | Лояльность | Шаблон карты. Привязка к бонусной программе. Поля скидок в карточке не работают (используйте автоскидки). |
| **Состояния заказов/лидов** | CRM | Этапы воронки. |
| **Шаблоны сообщений** | Коммуникации | Назначение (объект), текст с параметрами, вложения (печатные формы). |
| **Лиды** | CRM | Первичные обращения. Контакты хранятся в подчиненном справочнике. |

## Документы (Documents)
| Имя объекта | Роль | Движения / Особенности |
| :--- | :--- | :--- |
| **Заказ покупателя** | Обязательство | Регистр «Заказы покупателей» (приход). Резерв: пара записей в «Запасы» (расход без заказа, приход с заказом). |
| **Счет на оплату** | Запрос денег | Регистр «Оплата счетов и заказов» (оборотный). Не создает долг. |
| **Поступление на счет / ПКО** | Оплата | Приход по типу «Аванс» или погашение «Долга». Привязка к счету/заказу в расшифровке. |
| **Расходная накладная** | Отгрузка | 7 регистров (Запасы, Продажи, Расчеты, Доходы/Расходы и др.). Вид операции «Продажа покупателю» или «Возврат поставщику» и др. |
| **Приходная накладная** | Возврат | Вид операции «Возврат от покупателя». Сторнирует продажи. |
| **Корректировка реализации** | Исправление | Пишет разницу. Движения зависят от правки (цена или количество). Требует настройки. |
| **Отчет комиссионера** | Комиссия | Признает выручку и списывает себестоимость. Требует договор «С комиссионером» и услугу вознаграждения. |
| **Резервирование запасов** | Резерв | 6 видов операций (постановка/снятие с резерва). Пишет пару строк в регистр «Запасы». |
| **Массовая рассылка** | CRM | Не проводится. Создает очередь рассылок и события (если стоит флажок). |

## Регистры (Registers)
| Имя регистра | Тип | Что хранит |
| :--- | :--- | :--- |
| **Заказы покупателей** | Накопление | Остаток к отгрузке по заказам. |
| **Расчеты с покупателями** | Накопление | Долг (приход) и Аванс (расход). |
| **Запасы** | Накопление | Количество и стоимость. **Разрез «Заказ покупателя»** показывает резерв. |
| **Запасы на складах** | Накопление | Только количество (физическое наличие). |
| **Запасы к расходу со складов** | Накопление | Задел под накладную (создается расходным ордером). |
| **Продажи** | Оборотный | Выручка и себестоимость. |
| **Оплата счетов и заказов** | Оборотный | Сумма выставленная и сумма оплаченная. |
| **Предоставленные скидки** | Накопление | Информация о примененных автоскидках. |
| **Бонусные баллы** | Накопление | Начисление и списание баллов на картах. |

## Обработки (Data Processors)
| Имя обработки | Роль |
| :--- | :--- |
| **Прайс-лист** | Формирование и выгрузка цен. |
| **Прайс-листы контрагентов** | Загрузка цен поставщиков. |
| **Очередь расчета цен** | Фоновое регламентное задание для динамических цен. |
