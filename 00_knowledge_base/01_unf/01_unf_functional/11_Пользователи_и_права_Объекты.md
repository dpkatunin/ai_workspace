# 11. Пользователи и права. Объекты (Метаданные)

## Справочники (Catalogs)
| Имя объекта | Роль | Важные реквизиты и особенности |
| :--- | :--- | :--- |
| **Пользователи** | Учетные записи для входа | Полное имя, Вход в приложение разрешен, Недействителен, Имя для входа. Вкладка «Настройки входа» (пароль, аутентификация ОС). Связь с сотрудником через ссылку «Сотрудники пользователя». |
| **ГруппыДоступа** | Группы прав | Содержит ссылку на Профиль. Список участников (Пользователи). Вкладка «Виды доступа» (для RLS). |
| **ПрофилиГруппДоступа** | Наборы ролей | Основные (11) и Дополнительные (18). Вкладка «Разрешенные действия (роли)» для просмотра. |
| **Сотрудники** | Кадровый учет | Привязка к физлицу. Используется для зарплаты и выработки. |
| **ФизическиеЛица** | Анкетные данные | ФИО, дата рождения, паспортные данные, ИНН. Заводится до создания Пользователя. |
| **Контрагенты** | Клиенты/Поставщики | При включенном RLS появляется реквизит «Группа доступа» для разграничения видимости. |

## Обработки и механизмы
| Имя | Назначение |
| :--- | :--- |
| **Управление полнотекстовым поиском** | Окно (открывается из общих настроек) для обновления, очистки и проверки индекса. |
| **Персональные настройки пользователей** | Блок в «Настройках пользователей и прав», позволяющий скопировать настройки интерфейса (начальную страницу, избранное) от одного пользователя другому. |
| **Даты запрета изменения** | Настройка (в одноименном разделе), позволяющая блокировать редактирование документов до определенной даты. |
| **Журнал регистрации** | Хранит события, если включен переключатель «Регистрировать изменения прав доступа». |
| **Внешние отчеты и обработки** | Открываются только при наличии дополнительного профиля «Открытие внешних отчетов и обработок». |
