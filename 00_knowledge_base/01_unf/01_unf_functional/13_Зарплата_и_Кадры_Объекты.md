# 13. Зарплата и Кадры. Объекты (Метаданные)

## Документы (Documents)
| Имя объекта | Роль | Особенности |
| :--- | :--- | :--- |
| **Табель** | Учет рабочего времени | Буквенные коды (Я, ОТ, К, ВП и т.д.). Заполняется автоматически по производственному календарю. |
| **Начисление зарплаты** | Итоговый расчет | Собирает данные из табелей, нарядов, заданий. Кнопка «Заполнить и рассчитать». |
| **Сдельный наряд** | Сдельная оплата (производство) | Создается на основании «Заказа на производство». Требует флага «Закрыт» для начисления. |
| **Заказ-наряд** | Сдельная оплата (услуги) | Содержит вкладку «Зарплата» с распределением по исполнителям (% от суммы, тариф, фикс). |
| **Задание на работу** | Почасовые/временные работы | Содержит плановую трудоемкость. На его основе создается «Учет времени». |
| **Учет времени** | Фактические трудозатраты | Вводится на основании «Задания на работу». |
| **Платежная ведомость** | Выплата зарплаты | Может создаваться на Аванс или на Зарплату (заполняется по остаткам). |
| **Прием на работу** | Кадровый учет | Задает оклад, тарифную ставку, виды начислений и счет затрат. |
| **Расход из кассы / Расход со счета** | Фактическая выплата | Создается на основании Платежной ведомости. |

## Справочники (Catalogs)
| Имя объекта | Роль |
| :--- | :--- |
| **Сотрудники** | Карточки сотрудников (ФИО, паспорт, ИНН). |
| **Виды начислений и удержаний** | Настройка формул (Оклад по дням, Премия, Сдельный заработок и т.д.). |
| **Параметры расчетов** | Данные для формул (например, «ВыпущеноПродукции» из оборотов регистра). |
| **Графики работы** | Используются для заполнения табелей (Пятидневка и т.д.). |
| **Виды рабочего времени** | Справочник с кодами (Я, ОТ, К и их расшифровка). |

## Регистры (Registers)
| Имя регистра | Тип | Что хранит |
| :--- | :--- | :--- |
| **Сдельные наряды** | Накопление | Обороты по фактическому количеству (используется в запросах для формул). |
| **Выпуск продукции** | Накопление | Обороты по выпущенной продукции (для расчета премий). |
| **Расчеты с персоналом** | Накопление | Задолженность перед сотрудниками (начислено и выплачено). |
