# Введение — Объекты метаданных

> **Раздел:** 00_Введение
> **Обновлено:** 2026-10-20
> **Источники:** Дайджест статей по 1С:УНФ 3.0

Данный файл содержит карту основных объектов системы. Понимание того, какой документ или справочник за что отвечает, необходимо для правильного формирования базы знаний.

## Справочники (НСИ)
Основные справочники в УНФ 3.0 выведены в отдельное меню (раздел «Справочники»), чтобы не загромождать рабочие разделы.

| Объект | Назначение | Где в интерфейсе |
|---|---|---|
| **Организации** | Хранение реквизитов, систем налогообложения, подписей и банковских счетов. | Компания -> Организации |
| **Контрагенты** | Клиенты, поставщики. Есть кнопки быстрого создания документов («Продать», «Купить»), отображается долг. | CRM / Продажи / Закупки -> Контрагенты |
| **Номенклатура** | Товары, услуги, работы, наборы, тара. Показывает остатки, цены, позволяет подбирать аналоги. | Справочники -> Номенклатура |
| **Категории номенклатуры** | Группировка товаров. Позволяет привязывать к категории специфические свойства (доп. реквизиты). | Справочники -> Категории номенклатуры |
| **Склады** | Места хранения запасов. Могут быть оптовые, розничные, ордерные, с ячейками. | Справочники -> Склады и магазины |
| **Кассы / Банковские счета** | Точки приема наличных и расчетные счета организации. | Справочники -> Кассы / Банковские счета |
| **Сотрудники** | Физлица для кадрового учета, зарплаты и подотчетных сумм. | Справочники -> Сотрудники |
| **Пользователи** | Учетные записи для входа в программу, настройка прав доступа. | Настройки -> Пользователи и права |
| **Спецификации** | Рецепты/составы для производства продукции (что и сколько нужно для выпуска). | Производство -> Спецификации |
| **Виды цен** | Настройка типов цен (Закупочная, Оптовая, Розничная). | Справочники -> Виды цен |

## Документы (Оперативный контур)
Все документы разделены по бизнес-процессам. В УНФ 3.0 используются следующие наименования:

| Документ | Назначение | Движения / Влияние |
|---|---|---|
| **Заказ покупателя** | Фиксирует намерение клиента купить товар. Может резервировать товар на складе. | Не списывает товар, но резервирует остатки. |
| **Расходная накладная** | Факт отгрузки товара или оказания услуги клиенту. | Списывает товар со склада, формирует задолженность клиента. |
| **Приходная накладная** | Факт поступления товара от поставщика или возврата от клиента. | Увеличивает остатки на складе, формирует задолженность. |
| **Заказ поставщику** | Фиксирует потребность закупить товар. | Не меняет остатки. На основании создается Приходная накладная. |
| **Перемещение запасов** | Движение товара между складами. | Меняет остатки на двух складах. |
| **Инвентаризация запасов** | Фиксация фактического наличия товара. | Выявляет расхождения, создает документы Списания/Оприходования. |
| **Комплектация запасов** | Сборка/разборка товаров (создание комплектов). | Списывает комплектующие, приходует готовый комплект (и наоборот). |
| **Заказ на производство** | Задание на выпуск готовой продукции. | Резервирует материалы, создает задания для цеха. |
| **Производство (Отчет)** | Факт выпуска готовой продукции. | Списывает материалы и приходует готовую продукцию. |
| **Заказ-наряд** | Документ для оказания услуг, ремонта, монтажа. | Списывает материалы, фиксирует трудозатраты, формирует выручку. |
| **Поступление в кассу / Расход из кассы** | Движение наличных денежных средств. | Меняет остаток в кассе. |
| **Поступление на счет / Списание со счета** | Движение безналичных средств. | Меняет остаток на расчетном счете. |
| **Авансовый отчет** | Отчет подотчетного лица о потраченных суммах. | Списывает долг с сотрудника, приходует товары/услуги, фиксирует расходы. |
| **Ввод начальных остатков** | Специальный документ (помощник) для старта работы. | Вводит остатки денег, товаров, долгов на дату начала учета. |

## Отчеты (Аналитика)
Отчеты в УНФ 3.0 имеют гибкие настройки (группировки, фильтры, сортировки).

| Отчет | Что показывает | Раздел меню |
|---|---|---|
| **Пульс бизнеса** | Дашборд с ключевыми показателями (деньги, долги, продажи, прибыль). Настраивается под пользователя. | Главное / Начальная страница |
| **Прибыли и убытки** | Финансовый результат (выручка, себестоимость, расходы, чистая прибыль). | Компания -> Отчеты |
| **Остатки товаров** | Остаток, резерв и свободное количество в разрезе складов. | Склад -> Отчеты |
| **Движение товаров** | Товарная ведомость с разбивкой по хозяйственным операциям (приход/расход). | Склад -> Отчеты |
| **Воронка продаж** | Анализ этапов прохождения заказов и эффективность менеджеров. | Продажи -> Отчеты |
| **Расчеты с подотчетниками** | Контроль выданных под отчет денег и остатка задолженности сотрудников. | Деньги -> Отчеты |

## Связи между объектами
*   **Цепочка продажи:** `Заказ покупателя` -> `Расходная накладная` -> `Поступление на счет` (или `Поступление в кассу`).
*   **Цепочка закупки:** `Заказ поставщику` -> `Приходная накладная` -> `Списание со счета`.
*   **Цепочка производства:** `Заказ на производство` (по спецификации) -> `Производство` (выпуск) -> `Расходная накладная`.
*   **Подотчетные лица:** `Расход из кассы` (вид операции «Подотчетнику») -> `Авансовый отчет` -> `Поступление в кассу` (возврат неизрасходованных сумм).
*   **Резервирование:** При создании `Заказа поставщику` на основании `Заказа покупателя`, товары в нем автоматически попадают под резерв (неявная особенность логики УНФ).
