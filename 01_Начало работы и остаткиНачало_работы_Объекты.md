# Начало работы и остатки — Объекты метаданных

> **Раздел:** 01_Начало работы и остатки
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, SCloud

## Справочники (НСИ)

| Объект | Назначение в контексте старта | Где в интерфейсе |
|---|---|---|
| **Организации** | Хранение реквизитов, подписей, факсимиле, банковских счетов и налогов. | Компания -> Организации |
| **Подписи** | Справочник физлиц и должностей для подписи документов. | Компания -> Организации -> Подписи |
| **Номенклатура** | Карточки товаров и услуг, наследуют счета учета и НДС из категории. | Справочники -> Номенклатура |
| **Категории номенклатуры** | Задают базовые настройки для групп товаров (тип, НДС, счета). | Справочники -> Категории номенклатуры |
| **Контрагенты** | Клиенты и поставщики. Настройка разрезов взаиморасчетов. | Справочники -> Контрагенты |
| **Договоры** | Основание для расчетов с контрагентами. | Справочники -> Договоры |
| **Склады** | Места хранения для ввода остатков (имеют счет учета 10 или 41). | Компания -> Склады и магазины |
| **Кассы / Банковские счета** | Точки хранения денег (имеют счет учета 50 или 51). | Компания -> Кассы / Банковские счета |

## Документы

| Документ | Назначение | Движения / Влияние |
|---|---|---|
| **Ввод начальных остатков** | Специальный документ-помощник для старта. | Работает со служебным счетом «00». Не создает долгов, а фиксирует стартовое состояние (активы и пассивы). |
| **Расходная накладная / Приходная накладная** | Могут создаваться автоматически при вводе остатков (если включен флаг «Автоформирование документов расчетов»). | Пустые непроведенные документы для привязки долгов. |

## Регистры и служебные объекты
*   **Служебный счет 00:** Технический счет, на который относятся остатки при вводе (например, Дт 41 Кт 00).
*   **Регистр «Запасы на складах»:** Получает количественный приход при вводе остатков товаров.
*   **Регистр «Расчеты с покупателями/поставщиками»:** Хранит долги и авансы (разные типы расчетов).

## Связи между объектами
*   `Категория номенклатуры` -> определяет счета учета и НДС для `Номенклатуры`.
*   `Организация` -> задает систему налогообложения для документов и печатных форм.
*   `Ввод остатков (Деньги)` -> привязывается к `Кассам` или `Банковским счетам`.
*   `Ввод остатков (Товары)` -> привязывается к `Складам`.
*   `Ввод остатков (Расчеты)` -> привязывается к `Контрагентам` и `Договорам`.
