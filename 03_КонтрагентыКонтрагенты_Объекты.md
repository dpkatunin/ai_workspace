# Контрагенты — Объекты метаданных

> **Раздел:** 03_Контрагенты
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, 1С-Фреш

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Контрагенты** | Основной справочник покупателей, поставщиков и прочих лиц. |
| **Контактные лица** | Самостоятельный справочник людей. Связывается с контрагентами через регистр сведений. |
| **Договоры** | Справочник договоров. Подчинен контрагенту и организации. |
| **Категории договоров** | Группировка договоров и префиксы для нумерации. |
| **Роли контактных лиц** | Справочник ролей (по умолчанию пуст). |
| **Сегменты контрагентов** | Динамические группы (например, «Постоянные клиенты»). Настраиваются по правилам или вручную. |

## Документы

| Документ | Взаимодействие с контрагентом |
|---|---|
| **Заказ покупателя** | Создается на основании договора с покупателем. |
| **Расходная накладная** | Требует договор вида «С покупателем». |
| **Приходная накладная** | Требует договор вида «С поставщиком». |
| **Поступление на счет / Расход со счета** | В шапке договора нет, он указывается построчно в расшифровке платежа. |

## Регистры

| Регистр | Назначение |
|---|---|
| **Основные договоры** | Хранит признак основного договора для пары «Организация-Контрагент». |
| **Расчеты с покупателями / поставщиками** | Хранит долги и авансы с измерениями «Договор» и «Документ расчетов». |
| **История реквизитов** | Хранит старые и новые значения полей (КПП, Наименование) с датами начала действия. |

## Связи между объектами
*   `Контрагент` -> имеет флажки (Покупатель, Поставщик, Прочее).
*   `Контактное лицо` -> связывается с `Контрагентом` через регистр (должность задается в связке).
*   `Договор` -> подчинен `Контрагенту` и `Организации`. Задает `Вид цен`.
*   `Основной договор` (регистр) -> определяет, какой `Договор` подставится в новый документ.
*   `Категория договоров` -> задает префикс номера договора.
*   `Сегменты контрагентов` -> используются для скидок и отчетов.
