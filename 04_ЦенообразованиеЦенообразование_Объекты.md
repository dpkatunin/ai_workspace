# Ценообразование — Объекты метаданных

> **Раздел:** 04_Ценообразование
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, SCloud, RPS-1C

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Виды цен** | Колонки прайс-листа (Розничная, Оптовая, Закупочная). Задают тип расчета и правило НДС. |
| **Ценовые группы** | Группировка номенклатуры для настройки правил наценок и скидок. |
| **Виды скидок, наценок** | Именованные проценты. Наценка — это скидка с отрицательным процентом. |
| **Виды цен поставщиков** | Отдельный справочник для регистрации цен от поставщиков (включается опцией). |

## Документы

| Документ | Назначение |
|---|---|
| **Установка цен** | Фиксация цен на определенную дату по выбранным видам цен. Записывает данные в регистр «Цены номенклатуры». |
| **Расходная накладная** | Место применения ручных скидок (в форме «Цены и валюта»). Уменьшает выручку. |
| **Приходная накладная** | Место применения скидок поставщика (в строках). Уменьшает себестоимость партии. |

## Регистры

| Регистр | Назначение |
|---|---|
| **Цены номенклатуры** | Регистр сведений. Хранит историю цен с точностью до секунды. Измерения: Вид цен, Номенклатура, Характеристика. Ресурсы: Цена, Валюта. |
| **Предоставленные скидки** | Регистр накопления. Фиксирует сумму скидки по каждому товару в разрезе видов скидок и получателей. |
| **Продажи** | Регистр накопления. Содержит два ресурса: «Сумма» (фактическая выручка) и «Сумма без скидки» (для анализа упущенной выгоды). |

## Связи между объектами
*   `Виды цен` -> содержат настройки для расчета (базовый вид цен, наценка).
*   `Ценовые группы` -> привязываются к `Видам цен` для настройки индивидуальных наценок.
*   `Договор` -> задает `Вид цен` и `Вид скидки` по умолчанию для документов.
*   `Установка цен` -> создает записи в регистре `Цены номенклатуры`.
*   `Расходная накладная` -> применяет `Вид скидки` и формирует записи в регистре `Предоставленные скидки`.
