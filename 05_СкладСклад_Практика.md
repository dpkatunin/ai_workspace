## Чек-лист внедренца
- [ ] Включить «Несколько складов» и (при необходимости) «Разрешать склады в табличных частях».
- [ ] Создать структурные единицы с правильным типом (Склад, Розница, Подразделение).
- [ ] При необходимости включить «Ордерные склады» и настроить схему работы (по накладным или по ордерам).
- [ ] При необходимости включить «Ячеистые склады» и создать справочник ячеек (только для ордерных складов).
- [ ] Настроить хозяйственные операции для списания и оприходования (чтобы видеть причину в отчетах).
- [ ] Проверить настройки печати этикеток и ценников (для сканера штрихкодов).

## Частые ошибки и «грабли»

### Ошибка 1. Ожидание, что инвентаризация изменит остатки
**Симптом:** Провели «Инвентаризацию запасов», а товар на складе в учете не изменился.
**Причина:** У документа нет проведения. Он только фиксирует разницу.
**Решение:** На основании инвентаризации нужно создать «Оприходование» (на излишки) и «Списание» (на недостачи) или «Пересортицу».

### Ошибка 2. Пересортица «на основании» не проводится
**Симптом:** Создали «Пересортицу» из инвентаризации, а документ не проводится (ошибка по пустому счету).
**Причина:** Автозаполнение разбивает пару на две односторонние строки (в одной пусто поле приходуемой номенклатуры, в другой — списываемой).
**Решение:** Удалить автозаполнение и вручную свести обе номенклатуры в одну строку кнопкой «Сопоставить 2 строки».

### Ошибка 3. Путаница между «Комплектацией» и «Сборкой»
**Симптом:** Пытаются собрать мебель по спецификации, используя «Комплектацию запасов».
**Причина:** Это два разных документа. «Комплектация» — простая пересборка (доступна всегда). «Сборка» — производственный документ (требует включения подсистемы «Производство»).
**Решение:** Для физической сборки по рецептам используйте «Сборку» (со спецификациями). Для комплектации подарочных наборов — «Комплектацию».

### Ошибка 4. Не включается флажок «Учет по ячейкам»
**Симптом:** Пытаются включить ячейки на обычном складе, программа не дает.
**Причина:** Ячейки работают только на ордерных складах.
**Решение:** Включить ордерную схему на складе, затем включить учет по ячейкам. (Если по складу уже есть движения — создать новый склад).

### Ошибка 5. Перемещение не проводится из-за ордера
**Симптом:** Создали «Перемещение запасов», а программа требует ордер.
**Причина:** В карточке склада-отправителя или получателя включена ордерная схема при перемещении.
**Решение:** Сначала оформить складской ордер (приходный или расходный), затем перемещение (либо создать перемещение на основании ордера).

### Ошибка 6. Остаток по ячейкам не сходится с общим остатком
**Симптом:** В отчете «Склад» общий остаток один, а в «Остатках по ячейкам» другой.
**Причина:** Расхождение между регистром «Запасы» (количество+сумма) и «Запасы на складах» (адресный).
**Решение:** Проверить движения по документам. Возможно, движение прошло без указания ячейки (например, при списании).

### Ошибка 7. Хозяйственная операция не проверяется на смысл
**Симптом:** Списание порчи провели через операцию «Списание имущества», суммы ушли не туда.
**Причина:** Справочник «Хозяйственные операции» не проверяет логику при проведении.
**Решение:** Внимательно выбирать нужную операцию в шапке («Списание запасов» для порчи, «Списание на расходы» для материалов).

## Как проверить результат
1. Отчет «Склад» (вариант «Движение товаров по складам») должен показывать приход/расход.
2. В ордерной схеме отчет «Движения товаров по ордерным складам» не должен показывать расхождений (ордер без накладной).
3. В отчете «Запасы» (вариант «Себестоимость остатков») видна сумма остатков.
4. При списании материалов в производство себестоимость должна попасть в документ «Производство».
