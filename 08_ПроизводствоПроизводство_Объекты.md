# Производство — Объекты метаданных

> **Раздел:** 08_Производство
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, Корада, Ассистент

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Спецификации** | «Рецепты» изделий (состав материалов и операций). |
| **Виды производства (Этапы)** | Список этапов (Заготовка, Сборка, Покраска). |
| **Бригады** | Группы сотрудников для сдельных нарядов. |
| **Операции** | Номенклатура с типом «Операция» (для нарядов и спецификаций). |
| **Номера ГТД** | Декларации для импортных материалов (если используется импорт). |

## Документы

| Документ | Назначение |
|---|---|
| **Заказ на производство** | План выпуска. Не двигает остатки, резервирует материалы. |
| **Производство (Сборка запасов)** | Факт выпуска. Списывает материалы и приходует продукцию/отходы. |
| **Распределение затрат** | Распределяет прочие расходы (электричество, аренда) на себестоимость выпуска. |
| **Сдельный наряд** | Фиксация выработки сотрудников/бригад по операциям. |
| **Приходная накладная (Прием в переработку)** | Прием давальческого сырья. |
| **Отчет о переработке** | Отчет переработчика перед заказчиком (списание сырья, выпуск, услуги). |
| **Расходная накладная (Передача в переработку)** | Передача своего сырья переработчику (со стороны давальца). |
| **Отчет переработчика** | Приемка готовой продукции от переработчика (со стороны давальца). |

## Регистры

| Регистр | Назначение |
|---|---|
| **Заказы на производство** | Потребность в выпуске продукции. |
| **Этапы производства** | Фиксация выполнения этапов (для многоэтапного производства). |
| **Сдельные наряды** | Данные о выработке (нормочасы, расценки). |
| **Запасы** | Списание материалов и приход продукции/отходов (в суммовом и количественном выражении). |
| **Запасы и агентские услуги принятые** | Учет давальческого сырья (приход/расход). |
| **Спецификации по умолчанию** | Хранит признак основной спецификации для каждого изделия. |

## Отчеты

| Отчет | Назначение |
|---|---|
| **Себестоимость выпуска** | Показывает состав затрат (материалы, операции) на единицу продукции. |
| **План-фактный анализ себестоимости** | Сравнивает плановую и фактическую себестоимость выпуска. |
| **Распределение материалов** | Показывает, сколько какого материала ушло на каждое изделие. |
| **Запасы, принятые в переработку** | Остаток чужого сырья на складе переработчика. |

## Связи между объектами
*   `Спецификация` -> определяет состав для `Заказа на производство` и `Производства`.
*   `Заказ на производство` -> является основанием для `Производства` (списание материалов и выпуск).
*   `Производство` -> является основанием для `Отчета о переработке` (при давальческой схеме).
*   `Сдельный наряд` -> связан с `Производством` (операции) и `Сотрудниками` (начисление).
