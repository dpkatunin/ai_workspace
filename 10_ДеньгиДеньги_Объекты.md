# Деньги — Объекты метаданных

> **Раздел:** 10_Деньги
> **Обновлено:** 2026-10-20
> **Источники:** SCloud, 1С-Рарус, Lad, CoderStar

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Кассы** | Кассы организации (наличные) и кассы ККМ (фискальные регистраторы). |
| **Банковские счета** | Расчетные счета организации. |
| **Способы оплаты** | Наличные, платежные карты, кредит (для РМК). |
| **Подключаемое оборудование** | Драйверы ККТ, сканеров, эквайринговых терминалов. |
| **Статьи движения денежных средств (ДДС)** | Аналитика для отчетов (Оплата поставщикам, Выручка, Услуги банка и т.д.). |

## Документы

| Документ | Назначение |
|---|---|
| **Поступление в кассу** | Приход наличных (от покупателей, возврат от подотчетника). |
| **Расход из кассы** | Расход наличных (выдача подотчет, инкассация в ККМ, оплата поставщику). |
| **Поступление на счет** | Приход безналичных (оплата от клиента, поступление от банка по кредиту/эквайрингу). |
| **Списание со счета** | Расход безналичных (оплата поставщику, налоги, комиссия банка). |
| **Авансовый отчет** | Отчет сотрудника о потраченных подотчетных суммах. |
| **Чек ККМ** | Фискальный чек (розничная продажа). |
| **Чек коррекции** | Исправление ошибочного чека (только для ФФД 1.1+). |
| **Внесение денег** | Перемещение денег из кассы компании в кассу ККМ. |
| **Выемка денег** | Изъятие денег из кассы ККМ (инкассация). |
| **Корректировка долга** | Зачет авансов, перенос долга с одного договора на другой. |
| **Платежный календарь (план)** | Планирование поступлений и списаний. |

## Обработки

| Объект | Назначение |
|---|---|
| **Загрузка банковской выписки** | Импорт данных из клиент-банка для автоматического создания документов. |
| **Помощник настройки РМК** | Пошаговая настройка рабочего места кассира. |

## Регистры и отчеты

| Объект | Назначение |
|---|---|
| **Денежные средства** | Остатки по кассам и банковским счетам. |
| **Денежные средства в пути** | Деньги, внесенные в ККМ, но еще не оприходованные в кассу (и наоборот, при выемке). |
| **Расчеты с подотчетниками** | Контроль выданных и потраченных сумм по сотрудникам. |
| **Оплата счетов и заказов** | Регистр для планирования и контроля оплат. |
| **Кассовая книга** | Отчет для контроля наличной дисциплины (для ООО/ИП). |

## Связи между объектами
*   `Авансовый отчет` -> связан с `Расход из кассы` (выдача) или `Расход со счета` (на карту).
*   `Чек ККМ` (Кредит) -> связан с `Договор` (Банк) и `Поступление на счет` (оплата от банка).
*   `Выемка денег` -> переводит средства из `Касса ККМ` в `Денежные средства в пути`, затем `Поступление в кассу` зачисляет их в `Касса организации`.
*   `Поступление на счет` (Эквайринг) -> уменьшается на сумму комиссии, которая списывается через `Списание со счета` (Услуги банка).
