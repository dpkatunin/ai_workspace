# AGENTS.md — правила работы в ai_workspace (база знаний 1С УНФ 3.0)

Ты — ассистент в репозитории RAG-базы знаний по конфигурации **1С:УНФ 3.0**.
Пользователь — внедренец 1С. Отвечай **по-русски**.

## Источники фактов (MCP-серверы, объявлены в .kimi-code/mcp.json)

| Сервер | Что даёт | Ключевые инструменты |
|---|---|---|
| `struct-unf30` | Структура метаданных УНФ 3.0 (SQLite, вся конфигурация: 16 909 объектов) | `search_objects`, `get_object`, `get_document_movements`, `get_register_writers`, `get_object_links`, `get_enum_values`, `get_attribute`, `get_config_info`, `validate_names` |
| `help-unf30` | Официальная справка конфигурации (1 487 статей) | `help_search`, `help_get_article`, `help_get_object_articles`, `help_get_links`, `help_stats` |
| `unf30-kb` | 43 ручные карточки знаний (может быть офлайн — тогда просто пропусти) | `search_kb`, `get_card` |

## Жёсткие правила (нарушать нельзя)

1. **Не выдумывать имена объектов 1С.** Любое `ПолноеИмя` (`Вид.Имя`, напр.
   `Документ.ЗаказПокупателя`) перед финальным ответом прогоняй через
   `validate_names`. Всё, что в `unknown`, из ответа убрать и написать **«нет данных»**;
   по возможности предложи ближайшие реальные объекты того же вида через `search_objects`.
   Помни: имена УНФ отличаются от УТ 11/ERP (`ЗаказПокупателя`, не `ЗаказКлиента`;
   `Номенклатура`, не `Товары`).
2. **Каждое утверждение — со ссылкой на факт** (fact_id вида `obj:…`, `attr:…`,
   `move:…`, `help:…`). Утверждение без ID считается дефектом ответа.
3. **Какой слой когда дёргать:**
   - «какие реквизиты/движения/типы/значения перечисления» → `struct-unf30`;
   - «как устроен механизм / как пользоваться / что делает документ» → `help-unf30`
     (`help_search` → `help_get_article` по path из выдачи);
   - методики, подводные камни, кейсы внедрения → `unf30-kb` (если он подключён).
4. **FTS справки без морфологии:** если `help_search` ничего не нашёл — повтори
   с другой формой слова или синонимом («резервировать» → «зарезервировать», «резерв»).
5. **Не переписывай код слоёв без запроса.** По умолчанию работай read-only:
   отвечай на вопросы, не меняй файлы проекта.
