# ai_workspace — база знаний внедренца 1С для RAG-агента

## Что это

Репозиторий содержит базу знаний по 1С:УНФ 3.0 и память проектов, организованную так, чтобы по ней мог ходить ИИ-агент (DeepSeek + BDS) и отвечать на вопросы по внедрению с цитатами и статусом достоверности.

## 🚀 Быстрый старт для нового чата / участника
Если вы только что подключились к проекту, прочитайте:
1. **`_meta/handover.md`** — паспорт проекта (что сделано, что дальше, как работаем).
2. **`_meta/starter-prompt.md`** — готовый текст для инициализации нового чата.
3. **`_meta/index.md`** — карта базы знаний.

## Структура

- **`kb/`** — общие знания по конфигурациям (справочник по 1С).
- **`projects/`** — память конкретных проектов (лёгкий механизм: паспорт + ADR).
- **`_meta/`** — карта базы, правила ведения, глоссарий, промпт-навигатор, архитектурные решения.
- **`_source/`** — исходные материалы (архив). **Для ответов не используется** (см. ADR-002).
