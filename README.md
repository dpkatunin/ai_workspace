# ai_workspace — база знаний внедренца 1С для RAG-агента

## Что это

Репозиторий содержит базу знаний по 1С:УНФ 3.0 и память проектов, организованную так, чтобы по ней мог ходить ИИ-агент (DeepSeek + BDS) и отвечать на вопросы по внедрению с цитатами и статусом достоверности.

База разделена на два рабочих уровня:

- **`kb/`** — общие знания по конфигурациям (справочник по 1С).
- **`projects/`** — память конкретных проектов (лёгкий механизм: паспорт + ADR).

Плюс служебные каталоги:

- **`_meta/`** — карта базы, правила ведения, глоссарий, промпт-навигатор, архитектурные решения.
- **`_source/`** — исходные материалы (архив). **Для ответов не используется** (см. ADR-002).

## Принципы

1. **Один факт — одно место.** Остальное — ссылки по `id`.
2. **Метаданные — в YAML front matter.** Не в тексте.
3. **Статус достоверности обязателен.** `verified | draft | outdated`.
4. **Агент читает карту, а не всё подряд.** `_meta/index.md` → `_index.md` раздела → 1–3 карточки.
5. **Цитата и статус в ответе.** Без этого агент не отвечает.
6. **Архив (`_source/`) изолирован.** Агент его не читает.

## Быстрый старт

1. Репозиторий `github.com/dpkatunin/ai_workspace` (private).
2. В чате с агентом приложить `_meta/navigator-prompt.md` и `_meta/index.md`.
3. Задать вопрос. Агент сам подтянет нужные карточки.
