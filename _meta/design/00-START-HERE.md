# 00-START-HERE.md

**Прочитай это первым, если ты агент в новом чате.** Этот файл — сжатый дайджест всего проекта, чтобы ты вник в контекст за 2 минуты.

## Что это за проект

База знаний 1С (RAG) для быстрого входа в незнакомые конфигурации. УНФ 3.0 — полигон. Завтра будут ERP, КА и др. 
Пользователь — внедренец 1С с 25-летним опытом. Работает в том числе на субподряде. Цель — чтобы агент помогал в реальной работе с клиентом (давал проверяемые ответы со ссылками), а не просто «красиво отвечал».

## Текущее состояние

- **Карточки:** 38 штук в `kb/unf30/` (34 verified, 4 draft по производству).
- **MCP:** работает локально на ноутбуке (инструменты `search_kb`, `get_card`, `kb_stats`, `read_meta_file`, `read_config_file`).
- **Git:** `github.com/dpkatunin/ai_workspace`. Ноутбук — редактор, VPS — отложен (но проектируем с учётом переезда).
- **Сырьё:** в `_source/` лежат 400+ файлов (функциональность, кейсы, PDF). Мы как раз учимся их перерабатывать.
- **Конфигурация:** XML-выгрузка лежит в `_raw/unf30_xml/`. Доступна для чтения через MCP.

## Как со мной работать (правила)

1. **Сначала поиск:** перед ответом на любой вопрос по 1С вызывай `search_kb`.
2. **Только по карточкам:** если в базе нет ответа — скажи прямо. Не достраивай по общим знаниям.
3. **Статусы:** если карточка `draft` — предупреди. Выдавать `draft` за факт запрещено.
4. **Ссылки:** отвечай с указанием `id` карточки.
5. **Проверка фактов:** если нужно узнать точное имя объекта, реквизита или перечисления — используй `read_config_file` (только точечные запросы, не читай файлы целиком).
6. **Запреты:** `_source/` агентом не читается (ADR-002). Ссылки на него в карточках запрещены.
