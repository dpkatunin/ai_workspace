# История: три попытки

Не «набивание шишек», а карта пространства, которого не было. Нельзя узнать, чего можно хотеть, пока не потрогаешь руками.

## Попытка 1. «Свалка в чат»

**Что делал:** собрал кучу грязной информации в один чат, попытался натравить локального агента без переработки.

**Что сломалось:** агент тонул в шуме, отвечал не тем, цитировал мусор. Куча без структуры не работает.

**Урок:** нужна единица знания с границами. Отсюда — карточка.

## Попытка 2. «Умерший чат»

**Что делал:** проект жил в чате. Дошёл до определённого объёма — и застрял.

**Что сломалось:** чат — плохое хранилище. Закрылся — всё осталось в истории, к которой не вернуться. Чувство «ухожу не туда», но не было карты, куда надо.

**Урок:** нужна преемственность. Отсюда — Git и файлы. Проект должен переживать чат.

## Попытка 3 (текущая). «Структура»

**Что сделано:** карточки, статусы, индексы, MCP, валидатор, conventions, ADR. 34 verified + 4 draft по УНФ 3.0. R1 закрыт. MCP работает.

**Что вылезло:** не хватает объёма и автоматики. 400+ файлов сырья не переработать вручную. Верификация упирается в человека. Масштаб «38 карточек» сменился на «400+ и несколько конфигураций».

**Урок:** структура работает, но её надо кормить. Следующий уровень — автоматическое извлечение и сверка с конфигурацией.

## Траектория

```

Хранение → Преемственность → Масштабирование
(карточка)   (Git, файлы)     (автоматика, L2-верификация)

```

Каждая попытка решала узкое место предыдущей. Это не три провала — три уровня одной задачи.

## Главный сдвиг третьей попытки

**Критерий:** если завтра открыть новый чат с нуля — проект продолжится или умрёт?

- Попытка 1: умер бы.
- Попытка 2: умер.
- Попытка 3: **продолжится.** Карточки в Git, структура описана, MCP читает.

Это и есть главное: построена не «база знаний», а **система, которая переживает чат**.

## Чего не хватало раньше

Не знания «как делать», а **карты вариантов**: что вообще бывает по осям хранение / поиск / извлечение / верификация / интерфейс / память / агентность. Теперь эта карта есть — см. `05-open-questions.md`.
