# Извлечение встроенной справки 1С

Официальное руководство пользователя встроено в конфигурацию. Это самый чистый и легальный источник знаний (уровень `official`).

## Шаг 1. Выгрузить конфигурацию в XML

Используем Конфигуратор в пакетном режиме. В Windows cmd:

```bat
"C:\Program Files\1cv8\8.5.х.х\bin\1cv8.exe" DESIGNER /F "C:\ПутьКБазе" /N Админ /P Пароль /DumpConfigToFiles "C:\unf30_xml_dump"
```

*Если база серверная, вместо `/F` используем `/S "Сервер\ИмяБазы"`.*
*Выгрузка займёт время (5-20 минут в зависимости от размера базы).*

## Шаг 2. Извлечь файлы справки (с переименованием)

В выгрузке появятся папки `Documents/`, `Catalogs/` и т.д. Внутри каждого объекта будет `Ext/Help/ru.html`.

Запускаем скрипт извлечения:

```
py tools\extract_help.py --src "C:\unf30_xml_dump" --dst "_source\01_unf\official_help"
```

**Результат:** в `_source/01_unf/official_help/` появятся папки категорий (`Documents/`, `Catalogs/`, `DataProcessors/`), а внутри них — файлы `<ИмяОбъекта>.html`.

Пример структуры после извлечения:

```
_source/01_unf/official_help/
  Documents/
    РеализацияТоваровУслуг.html
    ПриходнаяНакладная.html
  Catalogs/
    Контрагенты.html
    Номенклатура.html
```

## Шаг 3. Конвертировать HTML в Markdown

Если нужно сразу получить текст для карточек, запускаем конвертер:

```
py tools\html_to_md.py --src "_source\01_unf\official_help" --dst "_source\01_unf\official_help_md"
```

**Результат:** в `official_help_md/` появятся `.md` файлы с текстом справки (заголовки, списки, таблицы). Картинки и скрипты отброшены.

## Шаг 4. Что дальше

Эти файлы — идеальное сырьё для генерации карточек `object` и `mechanism` со статусом `verified` (источник `official`).

Обрабатывать лучше пачками по разделам (например, только `Documents/`), чтобы не утонуть.

## Ограничения

- Таблицы в HTML-справке иногда сложные (объединённые ячейки), скрипт делает простое преобразование.
- Картинки (скриншоты интерфейса) не извлекаются — это нормально для текстовой базы.
- В некоторых версиях 1С справка может быть в `Help/ru.html` без `Ext/`. Скрипт ищет только `Ext/Help/`. Если у тебя другая структура — скажи, поправим фильтр.
