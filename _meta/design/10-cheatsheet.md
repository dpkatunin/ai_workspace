# Шпаргалка: режимы работы агента

## Команды

| Команда | Что делает |
|---|---|
| `/1c` | Включает режим 1С (обязательный `search_config` → GENERAL + CONFIG + KB) |
| `/1c off` | Выключает режим 1С |
| `/tags` | Показать эту таблицу |

**По умолчанию — обычный чат.**

## Обязательный порядок в `/1c`

1. `search_config` — до ответа. Хотя бы по одному имени объекта из вопроса.
2. GENERAL — логика.
3. CONFIG — проверка имён.
4. KB — поведение.

**Ответ без вызова `search_config` — недействителен.**

## Пример

> /1c Что делать с излишками при пересорте маркированной одежды?

Агент:
1. `search_config("возврат в оборот")` → `ВозвратВОборотИСМП` подтверждён.
2. `search_config("ввод в оборот")` → не найдено (такого документа нет).
3. Даёт логику (GENERAL), использует только подтверждённые имена (CONFIG), ссылается на KB (`unf30-pit-sklad`).

## Якорный пример

«Ввод в оборот» — не существует. Есть `ВозвратВОборотИСМП`. Русская формулировка ≠ имя объекта.

## Если MCP не отвечает

Одна попытка → «MCP недоступен, проверка не выполнена» → ответ с пометкой → предложение проверить сервер.

## Что важно

- **Отказ запрещён.** Лучше ответ с маркировкой, чем молчание.
- **Но и ответ без проверки имён — брак.** Оба правила действуют одновременно.
- «Не найдено» ≠ «нет». Формулировка — «не подтверждено».
- Формат XML-выгрузки: `.xml`, не `.yaml`.
- Подробно — `conventions.md` §10–12.1.
