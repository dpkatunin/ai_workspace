# 16-zipper-howto.md — Пошаговая инструкция запуска распаковщика

**Дата:** 2026-11-03 (обновлено: универсальный путь, проверка префикса)
**Статус:** принят
**Связанные:** `15-zipper.md` (код скрипта), `13-chat-migration.md` §9.

**⚠️ Два уровня путей:**
- **Распаковщик:** `$targetDir = "C:\ai_workSpaceGitHub"` (универсально, не меняется).
- **Агент:** формирует ZIP с префиксом репозитория (`ai_workspace/...` или `ai_workspace_projects/...`).

---

## Шаг 0. Подготовка (один раз)

1. Создайте папку `C:\tools\` (если её нет).
2. Скопируйте код `unzip-watcher.ps1` из `15-zipper.md` §3.1 в `C:\tools\unzip-watcher.ps1` (UTF-8 без BOM).
3. Создайте `C:\tools\Запуск распаковки.bat`:

```bat
@echo off
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0unzip-watcher.ps1"
pause
```

4. **Проверьте, что в `unzip-watcher.ps1` написано `$targetDir = "C:\ai_workSpaceGitHub"`** (без `\ai_workspace` в конце — универсально).
5. Убедитесь, что `C:\dsh-out` пуст (удалите старые ZIP и `.bad`).
6. Убедитесь, что оба клона существуют:

- `C:\ai_workSpaceGitHub\ai_workspace` (публичный)
- `C:\ai_workSpaceGitHub\ai_workspace_projects` (приватный, если нужен)
7. **Удалите папку `C:\ai_workSpaceGitHub\_meta`**, если она есть (мусор от прошлых распаковок без префикса).

---

## Шаг 1. Запуск (каждый раз)

1. **Двойной клик** по `C:\tools\Запуск распаковки.bat`.
2. Первая строка:

```
[2026-11-03 ...] Старт. Жду ZIP в C:\dsh-out → распаковка в C:\ai_workSpaceGitHub
```
3. **Не закрывайте окно.**

---

## Шаг 2. Скачивание ZIP из чата

1. Скачайте ZIP из чата (BDS → `C:\dsh-out\out.zip`).
2. **Не переименовывайте.**
3. В PowerShell появятся строки:

```
[2026-11-03 14:23:01] Найден: out.zip (12345 bytes, ...)
[2026-11-03 14:23:04] Размер стабилен: 12345 bytes
[2026-11-03 14:23:04] ZIP валиден. Записей: 6
[2026-11-03 14:23:04]   -> ai_workspace/_meta/design/00-START-HERE-v2.md
[2026-11-03 14:23:04]   -> ai_workspace/_meta/design/11-protocol-v2.md
[2026-11-03 14:23:04]   -> ...
[2026-11-03 14:23:05] Распаковано в C:\ai_workSpaceGitHub
[2026-11-03 14:23:05] ZIP удалён
```

**Критическая проверка в логе:** каждый entry начинается с `ai_workspace/` (или `ai_workspace_projects/`). **Если entry начинается с `_meta/`, `kb/`, `tools/` без префикса — ZIP сформирован неправильно** (см. `15-zipper.md` §4). Не начинайте работу, попросите агента перегенерировать.

---

## Шаг 3. Проверка (после каждой распаковки)

```
# 1. C:\dsh-out пуст (или только unzip.log)
dir C:\dsh-out

# 2. Файлы легли в ai_workspace, а не в корень
dir C:\ai_workSpaceGitHub\ai_workspace\_meta\design\*.md
# Ожидаем: свежие даты модификации

# 3. Контроль: в корне C:\ai_workSpaceGitHub не должно быть _meta, kb, tools
dir C:\ai_workSpaceGitHub\_meta
# Ожидаем: ошибка «путь не найден»
dir C:\ai_workSpaceGitHub\kb
# Ожидаем: ошибка «путь не найден»

# 4. Git видит изменения
cd C:\ai_workSpaceGitHub\ai_workspace
git status
```

**Если файлы в `C:\ai_workSpaceGitHub\_meta`** — ZIP был без префикса. Удалить мусор, перегенерировать ZIP.

---

## Шаг 4. Коммит (после проверки)

```
cd C:\ai_workSpaceGitHub\ai_workspace
git add -A
git commit -m "docs(meta): протокол v2, чекпоинт, распаковщик"
git push
```

---

## Шаг 5. Остановка

Закройте окно PowerShell или `Ctrl+C`. ZIP, скачанные после остановки, останутся в `C:\dsh-out` — следующий запуск их подхватит.

---

## Что делать, если что-то пошло не так

| Симптом ↕▾ | Что делать ↕▾ |
|---|---|
| −Окно не открывается | Правый клик на `unzip-watcher.ps1` → «Выполнить с помощью PowerShell» |
| «Выполнение сценариев отключено» | Запускайте через батник (`-ExecutionPolicy Bypass`) |
| «ОШИБКА: целевая папка не существует» | Нет `C:\ai_workSpaceGitHub`. Создайте или укажите правильный путь |
| ZIP не виден | Проверьте, что он в `C:\dsh-out`, а не в `Downloads` |
| «ZIP невалиден», `.bad` | Удалить `.bad`, перегенерировать ZIP |
| «Распаковано», но файлов нет в `ai_workspace` | Проверить `C:\ai_workSpaceGitHub\_meta` — если файлы там, ZIP без префикса |
| Файлы легли в `C:\ai_workSpaceGitHub\_meta` | ZIP без префикса. Попросить агента перегенерировать с `ai_workspace/...` |
| ZIP не удалился | Закрыть в проводнике/архиваторе, подождать 5 с |
| Несколько ZIP | Скрипт берёт самый новый. Старые удалить вручную |
⚙

---

## Что важно помнить

1. **Один экземпляр скрипта.** Не запускать параллельно.
2. **`C:\dsh-out` — только для ZIP от BDS.**
3. **`unzip.log` растёт.** Чистить раз в неделю.
4. **`git status` обязателен** перед коммитом.
5. **Битый ZIP** — `.bad` в папке = скрипт справился. Удалить и скачать заново.
6. **ZIP без префикса** — главная причина «файлы не ложатся». Проверять entries в логе.
7. **Корень для распаковки:** `C:\ai_workSpaceGitHub` (универсально).
8. **Клоны:** `ai_workspace` (публичный), `ai_workspace_projects` (приватный) — оба внутри `C:\ai_workSpaceGitHub`.
