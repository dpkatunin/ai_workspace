# Глоссарий и синонимы

Разговорные формулировки → термины 1С. Помогает агенту не промахиваться, когда пользователь говорит не так, как в конфигурации.

## Продажи

| Разговорное | В 1С:УНФ |
|---|---|
| Реализация | Расходная накладная (вид операции «Продажа покупателю») |
| Отгрузка | Расходная накладная |
| Счёт клиенту | Счёт на оплату |
| Оплата от клиента | Поступление на счёт / Поступление в кассу |
| Резерв | Резервирование запасов (регистр «Запасы», разрез «Заказ покупателя») |

## Закупки

| Разговорное | В 1С:УНФ |
|---|---|
| Поступление | Приходная накладная |
| Приёмка | Приходный ордер (при ордерной схеме) |
| Счёт от поставщика | Счёт на оплату (полученный) |
| Возврат поставщику | Расходная накладная (вид операции «Возврат поставщику») |
| Допрасходы | Дополнительные расходы |

## Склад

| Разговорное | В 1С:УНФ |
|---|---|
| Пересорт | Пересортица запасов |
| Недостача | Списание запасов |
| Излишек | Оприходование запасов |
| Ревизия | Инвентаризация запасов |
| Сборка | Комплектация запасов или Сборка запасов (производство) |

## Производство

| Разговорное | В 1С:УНФ |
|---|---|
| Рецепт | Спецификация |
| План выпуска | Заказ на производство |
| Факт выпуска | Документ «Производство» (в метаданных — «Сборка запасов») |
| Сдельщина | Сдельный наряд |
| Давальческое сырьё | Переработка давальческого сырья |
| Толлинг | Переработка давальческого сырья |

## Работы

| Разговорное | В 1С:УНФ |
|---|---|
| Ремонт | Заказ-наряд |
| Акт клиенту | Акт выполненных работ |
| Выработка | Сдельный наряд или Заказ-наряд (вкладка «Зарплата») |

## Деньги

| Разговорное | В 1С:УНФ |
|---|---|
| Подотчёт | Авансовый отчёт |
| Инкассация | Выемка денег → Поступление в кассу |
| Размен | Внесение денег в кассу ККМ |
| Эквайринг | Поступление на счёт (вид «Оплата по платёжным картам») |

## Учёт

| Разговорное | В 1С:УНФ |
|---|---|
| Закрытие месяца | Обработка «Закрытие месяца» |
| ОСВ | Оборотно-сальдовая ведомость |
| Книга продаж | Раздел 9 декларации по НДС |
| Книга покупок | Раздел 8 декларации по НДС |
