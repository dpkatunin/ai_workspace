# Паспорт проекта: База знаний 1С для RAG-агента

Этот файл — точка входа для нового чата или нового участника.

## 1. Что мы строим

База знаний по 1С:УНФ 3.0 для RAG-агента (внедренца-аналитика). Репозиторий: `github.com/dpkatunin/ai_workspace`.

Главная цель: агент отвечает на вопросы по внедрению, опираясь на проверенные карточки, с обязательной цитатой (`id`) и статусом (`verified` / `draft`).

## 2. Архитектура

- **Двухуровневый RAG:** `kb/` + `projects/`.
- **Изоляция источника:** `_source/` не читается агентом (только для ручного извлечения знаний) — ADR-002.
- **Типы карточек:** `object`, `mechanism`, `playbook`, `pitfall`, `case`.
- **Навигация:** `_meta/index.md` → `kb/unf30/_index.md` → 1–3 карточки.
- **Промпт агента:** `_meta/navigator-prompt.md` — открывать карточки, не использовать общие знания, статус из фронтматтера, при вопросах о регистрах — сразу в `by-movement.md`.
- **Индексы:** `by-synonym.md`, `by-movement.md` — по ADR-003 становятся генерируемыми (пока ручные, под валидацию).

## 5. Кладовая УНФ (стратегический ресурс)

Найдена база статей по УНФ (пример: «Производство в мебельных компаниях» от компании «Идея», `1c-idea.ru`).

**Как используем:** внешний источник. Скачиваем PDF/HTML в `_source/` (агент её не читает, ADR-002). Из статей вручную извлекаем структурированные карточки — 1 статья = 1–3 карточки. После извлечения обновляем `synonyms` во фронтматтере (по ADR-001) и секцию `## Движения` при необходимости.

**Что уже извлечено:**
- Механизм параметрических спецификаций и полуфабрикатов.
- Механизм назначения операций на исполнителей (Сдельный наряд).

**Что важно:** извлечённое из «Кладовой» попадает в базу сразу как `draft` — источник внешний, на практике в этой конфигурации не проверялся.

## 7. Правила имён и типов (из `conventions.md`)

- `id`: `unf30-<prefix>-<slug>`. `type` ≠ `prefix`.
- Имя файла: `<prefix>-<slug>.md`, без `unf30-`.
- Мета-файлы (`conventions.md`, `index.md`, `handover.md`, `checkpoints/*.md`, `decisions/*.md`) — без фронтматтера карточки (у ADR свой минимальный фронтматтер).
