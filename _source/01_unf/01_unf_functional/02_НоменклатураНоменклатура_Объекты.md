# Номенклатура — Объекты метаданных

> **Раздел:** 02_Номенклатура
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, Корада, RPS-1C

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Номенклатура** | Карточки товаров, услуг, работ. Основной справочник. |
| **Категории номенклатуры** | Шаблоны настроек (счета, НДС, тип) для групп товаров. |
| **Группы номенклатуры** | Иерархическое дерево папок внутри справочника Номенклатура. |
| **Сегменты номенклатуры** | Произвольные списки товаров для скидок/отчетов (включается в настройках). |
| **Характеристики номенклатуры** | Варианты товара (цвет, размер). |
| **Партии номенклатуры** | Аналитика поступления (срок годности, владелец). |
| **Серии номенклатуры** | Уникальные серийные номера. |
| **Ценовые группы** | Группы для настройки правил ценообразования. |
| **Виды цен** | Типы цен (Розничная, Оптовая, Закупочная). |
| **Единицы измерения** | Классификатор единиц (шт, кг, упак). |
| **Штрихкоды** | Регистр штрихкодов, привязанных к номенклатуре. |

## Документы

| Документ | Назначение |
|---|---|
| **Установка цен номенклатуры** | Фиксация цен на определенную дату по видам цен. |
| **Комплектация запасов** | Сборка или разборка комплектов (создание «Стола» из «Столешницы» и «Ножек»). |
| **Заказ на эмиссию кодов маркировки** | Заказ кодов Data Matrix в Честном ЗНАКе (для производителей). |
| **Маркировка товаров ИС МП** | Ввод кодов в оборот, маркировка остатков. |

## Регистры

| Регистр | Назначение |
|---|---|
| **Цены номенклатуры** | Хранит историю цен по видам цен. |
| **Запасы на складах** | Количественный учет остатков в разрезе складов, характеристик и партий. |
| **Штрихкоды** | Хранит соответствие штрихкода и номенклатуры. |

## Связи между объектами
*   `Категория` -> задает умолчания для `Номенклатуры` (счета, НДС, тип).
*   `Группа` -> определяет положение `Номенклатуры` в дереве.
*   `Характеристика` -> подчиняется `Номенклатуре` или `Категории`.
*   `Партия` -> подчиняется `Номенклатуре`.
*   `Установка цен` -> меняет записи в регистре `Цены номенклатуры`.
*   `Комплектация запасов` -> списывает комплектующие и приходует `Комплект` (Номенклатуру).
