# Склад — Объекты метаданных

> **Раздел:** 05_Склад
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, Ассистент, RPS-1C

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Склады и магазины** | Структурные единицы (Склады, Розничные склады, Подразделения, Группы складов). |
| **Ячейки склада** | Адреса хранения внутри конкретного склада (подчинен складу). |
| **Комплектации номенклатуры** | Шаблоны состава для документа «Комплектация запасов». |
| **Хозяйственные операции** | Справочник, задающий корреспонденцию счетов для Оприходования и Списания (например, «Оприходование запасов», «Списание имущества»). |
| **Подключаемое оборудование** | Сканеры штрихкодов, принтеры этикеток. |

## Документы

| Документ | Назначение |
|---|---|
| **Приходный ордер / Расходный ордер** | Физическое движение товара при ордерной схеме (без сумм). |
| **Приходная / Расходная накладная** | Финансовое движение товара (с суммами). |
| **Инвентаризация запасов** | Фиксация фактического наличия. Не меняет остатки. |
| **Оприходование запасов** | Приход излишков (или находка). Меняет остатки. |
| **Списание запасов** | Списание недостачи, порчи, брака. Меняет остатки. |
| **Пересортица запасов** | Зачет недостачи одной позиции излишком другой (одна строка — две номенклатуры). |
| **Перемещение запасов** | Движение товара между складами/цехами. |
| **Заказ на перемещение** | Планирование перемещения, резервирование на складе-отправителе. |
| **Перемещение по ячейкам** | Движение товара внутри одного склада между ячейками. |
| **Комплектация запасов** | Сборка/разборка по справочнику «Комплектации». |
| **Сборка запасов** | Производственный выпуск продукции по «Спецификациям». |

## Регистры

| Регистр | Назначение |
|---|---|
| **Запасы** | Главный регистр (количество и сумма). Нет измерения «Ячейка». |
| **Запасы на складах** | Складской регистр (только количество). Есть измерение «Ячейка». |
| **Запасы к поступлению на склады** | Товар, принятый по ордеру, но не оприходованный накладной. |
| **Запасы к расходу со складов** | Товар, отгруженный по ордеру, но не списанный накладной. |

## Отчеты

| Отчет | Назначение |
|---|---|
| **Склад** | Только количество (остатки, приход, расход). Есть вариант «Остатки по ячейкам». |
| **Остатки товаров** | Количество, резерв и свободный остаток. |
| **Движение товаров** | Ведомость с разбивкой по хозяйственным операциям. |
| **Запасы** | Количество и сумма (себестоимость). |
| **Ведомость в ценах номенклатуры** | Оценка склада по выбранному виду цен. |

## Связи между объектами
*   `Склады` -> задают тип (Склад, Розница) и настройки (Ордерный, Ячеистый).
*   `Приходный ордер` -> создается на основании `Приходной накладной` (или наоборот).
*   `Расходный ордер` -> создается на основании `Расходной накладной`.
*   `Инвентаризация` -> служит основанием для `Оприходования`, `Списания` или `Пересортицы`.
