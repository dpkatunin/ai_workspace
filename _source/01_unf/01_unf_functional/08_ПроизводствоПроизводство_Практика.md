# Производство — Практика

> **Раздел:** 08_Производство
> **Обновлено:** 2026-10-20
> **Источники:** Дайджест статей (CoderStar, Корада, Ассистент)

## Чек-лист внедренца
- [ ] Включить «Планирование и учет производственной деятельности» в настройках.
- [ ] Включить «Производство в несколько этапов» (если есть стадии) и «Технологические операции» (если нужны сдельные наряды).
- [ ] При работе с давальческим сырьем включить «Переработка давальческого сырья» и «Партии номенклатуры».
- [ ] Создать спецификации для всей производимой продукции (и для полуфабрикатов).
- [ ] Проверить наличие остатков материалов на складе перед созданием документа «Производство».
- [ ] Настроить статьи затрат для документа «Распределение затрат» (если используется).

## Частые ошибки и «грабли»

### Ошибка 1. «Заказ на производство» не двигает остатки
**Симптом:** Создали заказ, а материалы со склада не списались, продукция не появилась.
**Причина:** Заказ — это только план. Движения делает документ «Производство».
**Решение:** На основании заказа нужно создать документ «Производство» (или использовать АРМ «Выполнение этапов»).

### Ошибка 2. Ошибка «Обнаружено неверное распределение материалов»
**Симптом:** Документ «Производство» не проводится, если в нем несколько изделий.
**Причина:** При ручном распределении общее количество списываемого материала не совпадает с распределенным по изделиям.
**Решение:** Проверить вкладку «Распределение»: сумма количеств по изделиям должна быть равна общему количеству на вкладке «Материалы».

### Ошибка 3. Материал сверх спецификации не списывается
**Симптом:** Добавили материал в «Производство» вручную, а он не распределился на изделие.
**Причина:** При автоматическом распределении УНФ раскладывает только те материалы, которые есть в спецификации.
**Решение:** Переключить «Распределение» на «Ручное» и указать изделие вручную.

### Ошибка 4. Сдельный наряд не начисляет зарплату
**Симптом:** Провели наряд, но в расчетах с сотрудниками ничего не изменилось.
**Причина:** В настройках не включена опция «Управление персоналом, начисление зарплаты».
**Решение:** Включить опцию в разделе «Зарплата». Без нее наряд будет только фиксировать нормочасы и выработку.

### Ошибка 5. Брак не сохранился
**Симптом:** Отметили брак на этапах, но после перезаписи документа он исчез.
**Причина:** Брак фиксируется только если включены этапы производства, указан изготовитель-подразделение, указана спецификация и заполнены выполненные этапы.
**Решение:** Проверить все условия. Если поле «Брак на этапах» очищено, записи о браке удаляются.

### Ошибка 6. Ошибка при выключении «Переработки давальческого сырья»
**Симптом:** Пытаемся отключить переработку, программа выдает ошибку.
**Причина:** В базе уже есть движения по регистру «Запасы и агентские услуги принятые» (принимали сырье).
**Решение:** Отключить возможность можно только до первого приема давальческого сырья. В рабочей базе это невозможно.

### Ошибка 7. Отчет переработчика не проводится
**Симптом:** Ошибка «Не хватает запасов...» при проведении отчета о переработке.
**Причина:** Не проведен документ «Производство», который должен списать давальческое сырье.
**Решение:** Порядок строгий: Приход сырья -> Производство -> Отчет о переработке.

### Ошибка 8. Неверная себестоимость при разборке
**Симптом:** При разборке изделия на запчасти, одни запчасти стоят неоправданно дорого, другие дешево.
**Причина:** Неверно заполнена колонка «Доля стоимости» в спецификации.
**Решение:** Сумма долей должна быть равна 1. Распределить стоимость исходника между получаемыми продуктами (например, металл 0.3, пластик 0.7).

## Как проверить результат
1. Отчет «Себестоимость выпуска» показывает корректную сумму затрат по каждому изделию.
2. В карточке изделия на вкладке «Цены» видна себестоимость.
3. Отчет «Запасы, принятые в переработку» показывает нулевой остаток, если сырье полностью израсходовано.
