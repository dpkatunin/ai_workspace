# 11. Пользователи и права. Практика (Чек-листы и грабли)

## Чек-лист: Создание нового пользователя
1. Откройте «Настройки» -> «Настройка пользователей и прав» -> «Пользователи».
2. Нажмите «Создать». Заполните карточку физического лица (ФИО, личные данные) и запишите её.
3. В карточке пользователя заполните «Имя (для входа)» (логин).
4. На вкладке «Настройки входа» установите пароль.
5. Нажмите гиперссылку «Права доступа» -> «Включить в группу». Выберите нужную группу (например, «Продажи»).
6. При необходимости добавьте пользователя во вторую группу из папки «Дополнительные профили» (например, «Редактирование цен документов»).
7. Перезапустите программу и проверьте вход под новым пользователем.

## Чек-лист: Настройка запрета изменений (Закрытие периода)
1. Откройте «Настройки» -> «Настройка пользователей и прав» -> «Даты запрета изменения».
2. Поставьте флажок «Запрет изменения данных прошлых периодов».
3. Выберите способ применения: «Для всех пользователей» или «По пользователям».
4. Укажите дату запрета (вручную или выбрав «Конец прошлого месяца»).
5. При необходимости раскройте «Другие способы указания даты запрета» и ограничьте запрет конкретными разделами.

## Чек-лист: Включение и обновление поиска
1. Раздел «Настройки» -> «Общие настройки» -> группа «Поиск данных».
2. Поставьте галку «Полнотекстовый поиск данных».
3. Нажмите ссылку «Настроить». Посмотрите на статус индекса. Если написано «Обновление не требуется», поиск работает.
4. Если данные устарели, нажмите кнопку «Обновить индекс» и дождитесь завершения фонового задания.

## Чек-лист: Перенос интерфейса сотруднику
1. Настройте интерфейс под себя (начальную страницу, состав колонок).
2. Откройте «Настройки пользователей и прав» -> блок «Персональные настройки пользователей».
3. Найдите команду копирования настроек и выберите, кому из сотрудников передать свои настройки.

## Грабли (Частые ошибки)
*   **В базе может работать кто угодно.** Пока не создан первый пользователь, база открывается без пароля и с полными правами. Создавайте администратора сразу после установки.
*   **Ошибка при сохранении пользователя.** Если не заполнено «Имя (для входа)» или снят флажок «Вход в приложение разрешен», запись прервется ошибкой. Для сотрудников, которым не нужен вход в программу (только для начисления зарплаты), создавайте *Сотрудника*, а не *Пользователя*.
*   **Профиль «Администратор» не дает права открывать внешние обработки.** При попытке открыть внешний отчет появится предупреждение безопасности. Нужно добавить пользователя в дополнительный профиль «Открытие внешних отчетов и обработок».
*   **Уволили сотрудника — не удаляйте пользователя.** Если пользователь фигурирует в документах, его удаление приведет к ошибкам. Поставьте в карточке флажок «Недействителен» — вход закроется, а история сохранится.
*   **Поиск не находит новые документы.** Индекс строится фоновым заданием. После массового ввода данных нужно зайти в настройки поиска и нажать «Обновить индекс».
*   **Настройки интерфейса не переносятся на коллегу.** Раскладка панелей, избранное и история строго персональные. Их нужно передавать через обработку «Персональные настройки пользователей».
*   **Ограничение RLS не работает для отдельных контрагентов.** RLS ограничивает доступ только по *группам* контрагентов. Сначала создайте группы, распределите по ним клиентов, и только потом настраивайте права в группах доступа.
