# 12. CRM и работа с клиентами. Объекты (Метаданные)

## Документы (Documents)
| Имя объекта | Роль | Движения / Особенности |
| :--- | :--- | :--- |
| **Событие** | Звонки, встречи, письма | Не проводится. 6 типов. Первая строка участников — Контрагент. |
| **Задача сотрудника** | Внутренние поручения | Не проводится. Наименование = первая строка описания. |
| **Массовая рассылка** | E-mail и SMS рассылки | Не проводится. Ставит сообщения в очередь (регистр «Очередь рассылок»). |

## Справочники (Catalogs)
| Имя объекта | Роль |
| :--- | :--- |
| **Лиды** | Первичные обращения. |
| **Контакты лидов** | Подчиненный справочник для хранения телефонов/почты лида. |
| **Состояния лидов** | Этапы воронки («Не обработан», «В работе», «Завершен»). |
| **Источники привлечения** | Каналы (Сайт, E-mail, Звонок, Выставка, Рекламная кампания). |
| **Темы событий (шаблоны)** | Заготовки текста для событий. |
| **Состояния событий и заданий** | Запланировано, Завершено, Отменено. |
| **Календари сотрудников** | Создаются автоматически при записи пользователя. |
| **Причины завершения работы с лидом** | Справочник причин отказа (для блока потерь). |

## Регистры (Registers)
| Имя регистра | Тип | Что хранит |
| :--- | :--- | :--- |
| **История состояний лидов** | Сведений | Каждая смена этапа лида (дата, лид, состояние). |
| **История состояний заказов** | Сведений | Этапы заказов для воронки по заказам. |
| **Очередь рассылок** | Сведений | Строки для отправки писем/СМС. |
| **Отказались от рассылки** | Сведений | Адреса, нажавшие «Отписаться». |
| *(Напоминания)* | Сведений | Ключ: пользователь + время события + предмет. |
