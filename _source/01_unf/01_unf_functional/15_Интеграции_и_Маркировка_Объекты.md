# 15. Интеграции и Маркировка — Объекты

> **Раздел:** 15_Интеграции_и_Маркировка
> **Обновлено:** 2026-10-20
> **Источники:** CoderStar, 1С-Центр

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Виды продукции ИС МП** | Классификатор товарных групп для маркировки (обувь, одежда, табак и т.д.). |
| **Настройки интеграции с ИС МП** | Хранение токенов, идентификаторов и параметров обмена с ГИС МТ. |
| **Хозяйствующие субъекты ВетИС** | Сопоставление организации и площадок с данными из ФГИС «Меркурий». |
| **Пользователи ВетИС** | Сопоставление пользователей базы с пользователями ВетИС. |

## Документы

| Документ | Назначение |
|---|---|
| **Заказ на эмиссию кодов маркировки СУЗ** | Запрос кодов маркировки у Честного ЗНАКа (для производителей/импортеров). |
| **Маркировка товаров ИС МП** | Ввод кодов в оборот, маркировка остатков, агрегация. |
| **Отчет о переработке** | Для давальческой схемы (связан с маркировкой). |
| **Входящий УПД (ЭДО)** | Документ поступления, полученный по ЭДО. Требует сверки кодов маркировки. |
| **Исходящий УПД (ЭДО)** | Документ реализации, отправляемый контрагенту. |

## Регистры

| Регистр | Назначение |
|---|---|
| **Коды маркировки** | Хранение статусов и принадлежности кодов Data Matrix. |
| **Очередь обмена с ИС МП** | Очередь документов для отправки в ГИС МТ. |
| **Запасы и агентские услуги принятые** | Учет давальческого сырья (связано с переработкой). |
| **Состояния обмена с ВетИС** | Статусы гашения и создания эВСД. |

## Настройки и сервисы

| Объект | Расположение | Назначение |
|---|---|---|
| **Интеграция с ИС МП** | Настройки -> Маркировка | Включение товарных групп для Честного ЗНАКа. |
| **Обмен электронными документами** | Настройки -> Интеграции | Настройка ЭДО и ЭП. |
| **1С-Отчетность** | Настройки -> Интернет-поддержка и сервисы | Подключение сервиса сдачи отчетности. |
| **Настройки интеграции с ВЕТИС** | Администрирование | Подключение к шлюзу ВетИС.API. |
