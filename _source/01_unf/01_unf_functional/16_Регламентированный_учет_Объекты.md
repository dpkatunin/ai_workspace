# Регламентированный учет (Налоги и Бухгалтерия) — Объекты

> **Раздел:** 16_Регламентированный_учет_налоги
> **Обновлено:** 2026-10-20
> **Источники:** 1С:УНФ, Scloud

## Справочники (НСИ)

| Объект | Назначение |
|---|---|
| **Организации** | Карточка организации, вкладка «Налогообложение» (система, ставка НДС). |
| **Ставки НДС** | Список доступных ставок (22%, 10%, 5%, 7%, 0%, Без НДС). |
| **Номенклатура** | В карточке (вкладка «Учет») указывается ставка НДС (наследуется из категории). |
| **Категории номенклатуры** | Задают счета учета НДС и способ отражения в декларации. |
| **Счета учета** | План счетов (управленческий и регламентированный). |

## Документы

| Документ | Назначение |
|---|---|
| **Счет-фактура выданный** | Основание для Книги продаж. Создается на основании реализации. |
| **Счет-фактура полученный** | Основание для Книги покупок (вычет НДС). Регистрируется по приходу. |
| **Корректировка НДС** | Для исправления ошибок в счетах-фактурах (авансы, корректировки). |
| **Закрытие месяца** | Регламентная обработка (расчет себестоимости, амортизация, финансовый результат). |
| **Сведения об уплате налогов** | Для уменьшения УСН на страховые взносы (Единый налоговый счет). |

## Обработки и отчеты

| Объект | Назначение |
|---|---|
| **Книга покупок** | Отчет (раздел 8 декларации по НДС). |
| **Книга продаж** | Отчет (раздел 9 декларации по НДС). |
| **Журнал проводок** | Просмотр регламентированных проводок. |
| **Оборотно-сальдовая ведомость** | Проверка остатков и оборотов по счетам. |
| **Групповое перепроведение документов** | Настройки -> Администрирование -> Корректировка данных. |
| **1С-Отчетность** | Сервис для отправки деклараций (требует подписки ИТС). |

## Регистры

| Регистр | Назначение |
|---|---|
| **НДС предъявленный** | Учет входного НДС (для вычета). |
| **НДС начисленный** | Учет исходящего НДС. |
| **Расчеты по налогам** | Взаиморасчеты с бюджетом. |
| **Доходы и расходы УСН** | Налоговый учет для УСН. |

## Связи между объектами
*   `Организация` -> задает систему налогообложения и ставку НДС по умолчанию.
*   `Приходная накладная` + `Счет-фактура полученный` -> формируют запись в `Книге покупок`.
*   `Расходная накладная` + `Счет-фактура выданный` -> формируют запись в `Книге продаж`.
*   `Закрытие месяца` -> пересчитывает себестоимость и закрывает счета 90/91.
