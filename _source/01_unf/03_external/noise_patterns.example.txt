# Пример файла паттернов шума для tools/pdf_extract.py --strip-file
#
# Формат: name<TAB>regex
#   - name: короткое имя для отчёта (латиница, без пробелов)
#   - TAB: символ табуляции между name и regex
#   - regex: регулярное выражение Python (re), применяется с re.MULTILINE
#
# Строки, начинающиеся с #, игнорируются. Пустые строки — тоже.
#
# Зачем: каждый источник (статья, PDF, сайт) приносит свой boilerplate.
# Встроенные паттерны — только для конкретных известных случаев.
# Остальное — сюда, чтобы pdf_extract.py оставался универсальным.
#
# Как использовать:
#   py tools\pdf_extract.py article.pdf --strip-file noise_patterns.txt
#
# Как проверить, что сработало:
#   в выводе скрипта будет блок «шум сработал на страницах: p1:name1, p2:name2».
