# Universal-слой: методология, стандарты, шаблоны

> **Что это:** контент, применимый ко всем конфигурациям (unf, erp, zup, …).
> Не привязан к конкретной 1С-ке. Это «как вести проект» и «что генерировать».
>
> **Зачем:** M13 (генерация) использует эти шаблоны, чтобы создавать
> артефакты для четырёх ролей. Без universal-слоя M13 нечего генерировать.
>
> **Аналогия из 1С:** это как **общие механизмы конфигурации** — то, что
> работает одинаково для всех организаций. Не «настройка конкретного
> клиента», а «как устроена система».

## Структура

```

_universal/
├── README.md                    ← этот файл
├── methodology/                 ← методология внедрения
│   ├── stages.md                ← 5 этапов
│   ├── roles.md                 ← 4 роли
│   └── artifacts.md             ← что создаётся на каждом этапе
├── standards/                   ← стандарты практики
│   ├── document-standards.md    ← как оформлять документы
│   └── communication-standards.md ← как общаться с клиентом
├── competencies.yaml            ← связь KB ↔ компетенции
├── templates/                   ← шаблоны артефактов
│   ├── (для аналитика)
│   ├── (для внедренца)
│   ├── (для РП)
│   └── (для директора)
├── best-practices/              ← реестр лучших практик
│   └── README.md
└── org-mistakes/                ← реестр организационных ошибок
└── README.md

```

---

## Принципы

1. **Не привязано к конфигурации.** Если что-то специфично для УНФ —
   это в `_configs/unf/`, а не здесь.
2. **Шаблоны — скелеты, не готовые тексты.** M13 заполняет их
   данными проекта и KB.
3. **Стандарты — правила, не рекомендации.** «ТЗ должно содержать
   разделы X, Y, Z» — это стандарт, а не «хорошо бы».
4. **Реестры (best-practices, org-mistakes) — пустые при старте.**
   Наполняются по мере проектов.

## Связь с другими механизмами

| Механизм | Как использует universal-слой |
|---|---|
| **M13 (генерация)** | Берёт шаблоны из `templates/`, методологию из `methodology/` |
| **M7-full (поиск)** | Ищет в `_universal/` (тип `methodology`) |
| **M16 (кросс-проектный)** | Использует `best-practices/`, `org-mistakes/` |
| **M17 (портфель)** | Использует `competencies.yaml` |

---

## Что НЕ входит в universal-слой

- **Специфика конфигурации** (УНФ, ERP) — в `_configs/{config}/`.
- **Проектные артефакты** — в `01_projects/{project_id}/`.
- **Типовые знания по 1С** (как настроить склад) — в `_configs/{config}/`.
