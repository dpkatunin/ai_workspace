# Паттерн: нестандартное мебельное производство за 14 дней

## Контекст

Производитель серийной мебели вышел на рынок индивидуальных заказов. Процессы были заточены под серию: приём по каталогу, жёсткое планирование, фиксированные закупки, визуальный контроль комплектности. Управлять нестандартом «по-старому» стало невозможно.

## Решение

1. **Заказ с привязкой к этапам и ролям.** Менеджер, технолог, этапы. Менеджер сразу видит загрузку производства и называет сроки.
2. **Интеграция с ПО проектирования.** Спецификации изделий загружаются автоматически из программы проектирования, без ручного ввода.
3. **Планирование закупок** через «Расчёт потребностей» по остаткам и заказам.
4. **Планирование производства** по срокам из заказов, с фиксацией взятия в работу и отражением задержек.
5. **Контроль комплектности при упаковке** сканированием штрихкодов: деталь не из заказа — упаковка блокируется.
6. **ТСД на складе** для приёмки и отгрузки упаковок.
7. **Сдельная зарплата через штрихкоды**: сотрудник сканирует свой ID и деталь заказа, программа считает выработку.

## Нестандартные приёмы

- **Интеграция с CAD** — критична для нестандарта: ручной ввод спецификаций слишком трудоёмок и подвержен ошибкам.
- **Сканирование на каждом этапе** (упаковка, приёмка, отгрузка) — единственный способ исключить пересорт и недокомплект.
- **Сдельная зарплата через штрихкоды** — снимает нагрузку с бухгалтерии, делает расчёт прозрачным.

## Результаты

- 14 дней внедрения, 30 рабочих мест.
- Скорость обработки заказов ×2.
- 98% продукции выпускается в срок.
- Исключён брак поставки по пересорту и недокомплекту.
- Скорость расчёта сдельной зарплаты ×3.

## Когда применять

- Производство по индивидуальным заказам с проектированием.
- Есть CAD/PLM, который можно интегрировать.
- Высокая цена ошибки в комплектности (мебель, металлоконструкции, сборные изделия).
- Готовность к сканированию на этапах (ТСД, сканеры).

## Когда не применять

- Серийное производство с фиксированной номенклатурой — интеграция с CAD избыточна.
- Малые объёмы без проблем с комплектностью — сканирование не окупится.
