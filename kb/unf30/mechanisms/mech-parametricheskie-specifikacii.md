# Механизм: Параметрические спецификации

## Суть

Параметрическая спецификация — спецификация, в которой вместо фиксированного количества материалов заданы **параметры** (материал фасада, материал корпуса, высота) и **формулы**, по которым программа рассчитывает количество материала или выбирает нужную номенклатуру.

Отличие от обычной спецификации: обычная — фиксированный набор материалов и операций; параметрическая — «калькулятор», который пересчитывается под конкретный заказ.

## Где включается

- Справочник **«Спецификации»** (`unf30-cat-specifikaciya`).
- Признак использования формул — реквизит **`ИспользуетсяРасширение`**.
- Признак шаблона — реквизит **`ЭтоШаблон`** (шаблон параметрической спецификации).
- `ВидПроизводства` — ссылка на `Справочник.ВидыПроизводства`.

> Точное имя реквизита «вид спецификации — параметрическая» в источнике не указано. В конфигурации явного реквизита «ВидСпецификации» не обнаружено — параметричность, вероятно, определяется через `ИспользуетсяРасширение` + `ЭтоШаблон`. Проверить на форме.

## Как работает

### Параметры

Набор параметров зависит от изделия. В источнике для мебели:

- материал фасада;
- материал корпуса;
- высота.

Параметры могут быть:

- числовыми (высота, ширина) — используются в формулах;
- перечислимыми (материал) — используются для выбора номенклатуры;
- логическими (галочка «Blum») — используются в условиях.

### Формулы

Внутри спецификации прописываются формулы расчёта. Пример формулы из источника (стр. 6):

```

[Спецификация.Высота в мм ("Общие")] * [Спецификация.Ширина в мм ("Общие")] * 2 / 1000000

```

Формула может рассчитывать:

- количество материала;
- характеристики материала;
- выбор самой номенклатуры материала.

### Условия

Из источника: «Если поставить галочку Blum, то по формуле будет выбираться набор фурнитуры Blum, если галочка не будет проставлена, то будет использован набор китайской фурнитуры».

То есть параметрическая спецификация может содержать не только арифметику, но и **ветвление** по значению параметра.

## Пример из источника

Шкаф = фасад + корпус + фурнитура Blum. Операции: «сборка», «установка». Фасад и корпус — полуфабрикаты собственного производства (см. `unf30-mech-specifikacii-s-polufabrikatami`).

## Требует проверки на практике (L3)

> Структура справочника подтверждена XML. Синтаксис и поведение формул — нет.

- **Синтаксис редактора формул**: совпадает ли с примером `[Спецификация.Высота в мм ("Общие")] * …` на реальной базе.
- **Поддержка условий**: реализуется ли ветвление (Blum / китайская фурнитура) внутри формулы, или через отдельные строки состава / отдельные спецификации.
- **Точное имя реквизита**, включающего параметрический режим (в конфигурации найдены только `ИспользуетсяРасширение` и `ЭтоШаблон`).
- В каком именно документе выбираются параметры: заказ покупателя, заказ на производство, или оба.

## Связи

- `unf30-cat-specifikaciya` — справочник спецификаций.
- `unf30-mech-specifikacii-s-polufabrikatami` — спецификации с полуфабрикатами (соседний механизм).
- `unf30-doc-zakaz-na-proizvodstvo` — где выбираются параметры и планируются операции.
- `unf30-doc-proizvodstvo` — факт выпуска.
- `unf30-pit-specifikacii` — грабли спецификаций.
