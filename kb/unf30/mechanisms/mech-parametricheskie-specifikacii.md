# Механизм: Параметрические спецификации

## Суть

Параметрическая спецификация — это спецификация, в которой вместо фиксированного количества материалов заданы **параметры** (например, материал фасада, материал корпуса, высота) и **формулы**, по которым программа сама рассчитывает количество материала или выбирает нужную номенклатуру.

Ключевое отличие от обычной спецификации: обычная спецификация — это фиксированный набор материалов и операций; параметрическая — «калькулятор», который пересчитывается под конкретный заказ.

## Где включается

- Справочник **«Спецификации»** (`unf30-cat-specifikaciya`).
- Вид спецификации — **параметрическая** (точное имя реквизита в источнике не указано — проверить на конкретной конфигурации).
- Параметры задаются в самой спецификации и затем выбираются в заказе покупателя / заказе на производство.

## Как работает

### Параметры

Набор параметров зависит от изделия. В источнике для мебели приведены:
- материал фасада;
- материал корпуса;
- высота.

Параметры могут быть:
- числовыми (высота, ширина) — используются в формулах;
- перечислимыми (материал) — используются для выбора номенклатуры;
- логическими (галочка «Blum») — используются в условиях.

### Формулы

Внутри спецификации прописываются формулы расчёта. Пример формулы из источника (скриншот, стр. 6):

```

[Спецификация.Высота в мм ("Общие")] * [Спецификация.Ширина в мм ("Общие")] * 2 / 1000000

```

Формула может рассчитывать:
- количество материала;
- характеристики материала;
- выбор самой номенклатуры материала.

### Условия

В источнике приведён пример с фурнитурой: «Если поставить галочку Blum, то по формуле будет выбираться набор фурнитуры Blum, если галочка не будет проставлена, то будет использован набор китайской фурнитуры».

То есть параметрическая спецификация может содержать не только арифметику, но и **ветвление** по значению параметра.

## Пример из источника

Шкаф состоит из фасада, корпуса и фурнитуры Blum. За шкафом закреплены операции «сборка» и «установка». Фасад и корпус — полуфабрикаты собственного производства (отдельная карточка — в работе).

## Подводные камни

> В источнике подводные камни не описаны. Ниже — только те, что уже зафиксированы в базе по смежной теме (`unf30-pit-specifikacii`), с пометкой «проверить». Остальное — заполнить после проверки на практике.

- **Параметрическая спецификация не пересчиталась** — проверить, что все параметры заполнены в заказе (см. `unf30-pit-specifikacii`, п. «Параметрическая спецификация не рассчитывается»).
- **В заказе осталась старая спецификация** — заказ фиксирует состав на момент создания, изменения в спецификации не пересчитывают уже созданные документы (см. `unf30-pit-specifikacii`).

## Связи

- `unf30-cat-specifikaciya` — справочник спецификаций.

- `unf30-doc-proizvodstvo` — факт выпуска.
- `unf30-pit-specifikacii` — грабли спецификаций.
