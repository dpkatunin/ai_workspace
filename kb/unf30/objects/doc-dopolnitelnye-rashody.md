# Документ «Дополнительные расходы»

## Назначение

Включает в себестоимость уже принятого товара расходы, которые пришли отдельно от накладной: доставку, погрузку, услуги склада, таможенное оформление (если не через «Расходы при импорте»). Без него себестоимость занижена, а валовая прибыль завышена.

Логика проста: приходная накладная закрыла товар по цене поставщика, а доставка пришла отдельным счётом через неделю. Если её не распределить, товар на складе будет числиться дешевле, чем он реально обошёлся.

## Ключевые реквизиты шапки

- **Организация** — задаёт систему налогообложения.
- **Контрагент** — перевозчик или подрядчик (не поставщик товара).
- **Договор** — разрез взаиморасчётов с подрядчиком.
- **Способ распределения** — по сумме или по количеству.

## Табличные части (вкладки)

- **Товары** — строки из приходной накладной, на которые распределяется расход. Заполняется по кнопке «Заполнить → По документу поступления».
- **Услуги** — что именно вы купили (доставка, погрузка). Сюда вносится сумма расхода.
- **Распределение** — коэффициенты, по которым сумма услуг раскладывается по товарам.

## Движения

| Регистр | Что пишет |
|---|---|
| Запасы | Увеличивает стоимость остатка товара (сумма, количество не меняется) |
| Расчёты с поставщиками | Долг перед подрядчиком за услугу |

## Связи

- **Основание:** Приходная накладная (товар уже принят).
- **Связанные документы:** `unf30-doc-prikhodnaya-nakladnaya`, `unf30-pit-zakupki`.

## Типовые ошибки

- **Сумма не распределена.** Документ не проводится с ошибкой «Сумма услуг не равна распределённой сумме». Лечится кнопкой «Распределить услуги».
- **Расход лёг только на остаток.** Проданные ранее единицы не пересчитываются. Вводить документ нужно сразу после получения счёта, а не через месяц.
- **Перепутали контрагента.** В шапке должен быть подрядчик (перевозчик), а не поставщик товара. Иначе долг повиснет на поставщике и исказит взаиморасчёты.

Подробнее — `unf30-pit-zakupki`.
