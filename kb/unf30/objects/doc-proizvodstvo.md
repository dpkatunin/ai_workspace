# Документ «Производство» (Сборка запасов)

## Назначение

Главный документ, фиксирующий факт выпуска готовой продукции. Именно он, в отличие от «Заказа на производство», делает реальные движения: списывает материалы со склада и приходует готовую продукцию (и возвратные отходы).

**Имя в метаданных:** `СборкаЗапасов`. **Синоним:** «Производство». (Не наоборот: в интерфейсе видно «Производство», в коде — `СборкаЗапасов`.)

## Виды операций

Перечисление `ВидыОперацийСборкаЗапасов`, значение по умолчанию — **«Сборка»**. Второе значение — «Разборка».

## Ключевые реквизиты шапки

| Реквизит | Синоним в интерфейсе | Назначение |
|---|---|---|
| `Организация` | Организация | Система налогообложения и ставка НДС |
| `ВидОперации` | Операция | Сборка / Разборка |
| `СтруктурнаяЕдиница` | **Изготовитель** | Склад или производственное подразделение, где происходит выпуск |
| `СтруктурнаяЕдиницаЗапасов` | Списать из | Откуда списываются материалы |
| `СтруктурнаяЕдиницаПродукции` | Получатель | Куда приходуется продукция |
| `СтруктурнаяЕдиницаОтходов` | Получатель отходов | Куда приходуются возвратные отходы |
| `ЗаказНаПроизводство` | Заказ на производство | Ссылка на заказ |
| `ЗаказПокупателя` | Заказ покупателя | Резерв продукции под клиента |
| `ПлановаяОценка` | Плановая оценка | Вид цен для плановой оценки |

Обратите внимание: это **четыре разных поля структурных единиц**, а не одно «Подразделение».

## Табличные части (вкладки)

- **Продукция** — что выпускаем. Указывается количество и спецификация. В колонке «Брак на этапах» фиксируется брак (доступно при включённых этапах).
- **Материалы** — что списываем. Если изделий несколько — переключатель «Распределение»: *Автоматическое* (по нормам спецификации) или *Ручное*.
- **Отходы** — возвратные отходы (опилки, обрезки).
- **Дополнительные реквизиты** — расширяемые свойства.

## Движения

Документ пишет в 28 регистров. Ключевые накопления:

| Регистр |
|---|
| `РегистрНакопления.Запасы` |
| `РегистрНакопления.ЗапасыНаСкладах` |
| `РегистрНакопления.ВыпускПродукции` |
| `РегистрНакопления.ЗаказыНаПроизводство` |
| `РегистрНакопления.ПотребностьВЗапасах` |
| `РегистрНакопления.ЭтапыПроизводства` |
| `РегистрНакопления.РезервыТоваровОрганизаций` |
| `РегистрНакопления.ЗапасыИАгентскиеУслугиПринятые` |

Дополнительно документ пишет в `РегистрБухгалтерии.Управленческий` и в ряд регистров сведений (прослеживаемость, серии, НДС). Полный список — запросом `search_config` или чтением `Documents/СборкаЗапасов.xml`.

## Связи

- **Основание:** Заказ на производство (через реквизит), Заказ покупателя.
- **На основании документа:** Приходный ордер, Расходный ордер, сам «Производство» (цепочка).
- **Связанные справочники:** Спецификации, Номенклатура, Структурные единицы.

> Тонкость: `ЗаказНаПроизводство` есть как реквизит-ссылка, но **не входит в список `ДокументОснование`**. То есть ввести «Производство» на основании заказа через типовой механизм «Создать на основании» нельзя — связь через реквизит вручную.

## Типовые ошибки

- Материал сверх спецификации не списывается — переключить распределение на ручное.
- Брак не сохраняется — проверить условия фиксации (этапы, спецификация, подразделение).
- Неверная себестоимость при разборке — проверить заполнение доли стоимости в спецификации.
