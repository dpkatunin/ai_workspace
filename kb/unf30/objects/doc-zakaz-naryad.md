# Документ «Заказ-наряд»

## Назначение

Документ «Заказ-наряд» — это главный операционный документ для оформления процесса выполнения работ (ремонт, монтаж, сервис). Он собирает воедино перечень работ, списывает материалы (запчасти, расходники) и фиксирует трудозатраты исполнителей. На его основании формируется финансовый документ «Акт выполненных работ» для выставления счета клиенту.

## Ключевые реквизиты шапки

- **Организация** — задаёт систему налогообложения.
- **Заказчик (Контрагент)** — клиент, для которого выполняются работы.
- **Договор** — основание для расчётов.
- **Склад** — откуда списываются материалы (запчасти).
- **Состояние** — статус заказа-наряда (например, «Принят», «В работе», «Выполнен», «Закрыт»).

## Табличные части (вкладки)

- **Работы** — перечень выполняемых работ (номенклатура с типом «Работа»).
- **Материалы** — запчасти и расходники, которые списываются на выполнение работ.
- **Зарплата** — распределение трудозатрат по исполнителям (процент от суммы, тариф, фикс).

## Движения

| Регистр | Что пишет |
|---|---|
| Запасы | Списание материалов (запчастей, расходников) |
| Сдельные наряды | Фиксация выработки исполнителей (если используется) |
| Выручка/Долг | **Не пишет.** Выручка формируется только документом «Акт выполненных работ» |

## Связи

- **Основание:** Заказ покупателя (если работы под конкретный заказ).
- **Продолжение:** Акт выполненных работ (реализация).
- **Связанные справочники:** Номенклатура (типы «Работа», «Услуга»), Состояния заказ-нарядов.

## Типовые ошибки

- Использование только «Акта выполненных работ» без «Заказ-наряда» — приводит к тому, что материалы списываются обычным «Списанием запасов», а трудозатраты нигде не фиксируются.
- Неверный тип номенклатуры (выбран «Запас» вместо «Работа») — программа не даст корректно сформировать акт.
