# Установка цен номенклатуры

## Что это

Документ «Установка цен номенклатуры» фиксирует цены на номенклатуру по конкретному виду цен на дату. Это «ручка»: при проведении документ пишет записи в периодический регистр сведений **«Цены номенклатуры»**. Все документы продажи (реализация, заказ, счёт) читают цену именно из этого регистра на дату документа — не из самого документа установки.

Связка трёх объектов:

| Объект | Роль |
|---|---|
| Справочник **«Виды цен номенклатуры»** | Перечень видов цен (Розничная, Оптовая, Закупочная…). У каждого — валюта, галка «Цена включает НДС», способ округления, процент наценки. |
| Документ **«Установка цен номенклатуры»** | Фиксирует цены по одному виду на дату. Пишет в регистр. |
| Регистр сведений **«Цены номенклатуры»** | Периодический регистр (номенклатура × характеристика × вид цены). «Память» системы о ценах. |

Мнемоника: справочник — «какие бывают цены», документ — «действие», регистр — «где лежит результат».

## Структура документа

- **Шапка:** дата, вид цен (один на документ), валюта (наследуется из вида цен).
- **Табличная часть:** номенклатура, характеристика (если у номенклатуры включена), цена, старая цена (для справки).
- Один документ = один вид цен. Несколько видов — несколько документов.

## Как это работает (пошагово)

1. Заводите **вид цены** в справочнике. Заполняете: валюта, «Цена включает НДС», способ округления, при необходимости — процент наценки от базового вида.
2. Один из видов помечаете как **основной** — по нему по умолчанию подставляется цена в документах продажи.
3. Создаёте **документ «Установка цен»**: вид цен, дата, заполняете ТЧ ценами.
4. Проводите документ — он пишет записи в регистр «Цены номенклатуры» с периодом = дате документа.
5. Документы продажи при подстановке цены читают регистр на дату документа.

## Ключевые реквизиты вида цен

- **Валюта** — цена в валюте вида.
- **Цена включает НДС** — самая частая причина неверных сумм. Если галка стоит → в документе цена уже с НДС, НДС выделяется расчётным методом. Если не стоит → цена без НДС, НДС начисляется сверху. См. [[unf30-pit-ceny]], п.2.
- **Способ округления** — по арифметике, вверх, вниз; до 0.01 / 0.1 / 1 и т. д. Округление применяется при записи в регистр, все суммы дальше считаются от округлённой цены.
- **Процент наценки** — автоматический расчёт нового вида цен от базового. Срабатывает **в момент установки цен**, а не в момент продажи. См. [[unf30-mech-skidki-nacenki]].

## Чем цена в документе отличается от цены в регистре

- **Цена в регистре** — «справочная», по виду цен на дату. Используется для автоподстановки.
- **Цена в документе** — «фактическая», зафиксирована в момент создания/проведения документа продажи. Может отличаться от регистра (ручная правка, скидка).
- Проведение реализации **не меняет** цену в регистре. Изменение цены — только новым документом «Установка цен».

Отсюда следствие: установили новые цены — старые документы продажи не пересчитываются (историчность цен). Это нормально, см. [[unf30-pit-ceny]], п.6.

## НДС в цене

Два режима работы (задаются галкой «Цена включает НДС» в виде цен):

| Режим | Что в документе | Как считается НДС |
|---|---|---|
| Галка **стоит** | Цена уже с НДС | НДС выделяется из суммы расчётным методом |
| Галка **не стоит** | Цена без НДС | НДС начисляется сверху |

Один и тот же товар по разным видам цен может иметь разные настройки — это допустимо, но требует дисциплины при настройке.
