# Проекты

Лёгкая память проектов: паспорт + ADR. Без протоколов встреч и ТЗ — только ссылки.

## Состав проекта

```

projects/<client>/
├── _project.md          # паспорт проекта
└── decisions/
└── ADR-001.md       # архитектурные решения

```

## Правила

- Паспорт — 10–15 полей, не больше.
- ADR — короткая запись решения: контекст, решение, альтернативы, последствия.
- Встречи, ТЗ, переписка — не тащить в RAG. Только ссылки.
- Клиентские данные — обезличенно.
