## Что за проект

ИИ-база знаний (RAG) по конфигурации 1С **УНФ 3.0**. Пользователь — внедренец с 25-летним опытом. Цель: давать проверяемые ответы, не галлюцинировать.

**Главный вывод:** поведение нельзя гарантировать промптом. Правильность обеспечивается **кодом и структурой данных**.

## Ключевые решения (не пересматривать без причины)

1. **STRUCT → SQLite**, не векторную БД. Точный поиск по именам надёжнее семантики.
2. **`Раскрытие` из выгрузки не храним** — граф из `Типы` + `СвойстваОбъекта`.
3. **`СвойстваОбъекта` — в колонки + JSON.** Без `register_kind` модель путает регистры.
4. **ID фактов стабильные:** `obj:Документ.ЗаказПокупателя`, `attr:…`, `move:…`, `link:…`.
5. **Лимит 10–15 КБ на ответ MCP-инструмента.** Большие массивы обрезаются с `truncated`.
6. **Валидатор имён — код.** Все `ПолноеИмя` проверяются по `objects.full_name` через `validate_names`.
7. **`ijson`, не `json.load`.** Файлы полной выгрузки 10–50 МБ.
8. **Подсистема — измерение в `objects`:** `subsystem` = верхний уровень (`Подсистема.ПутьРодителей[0]` или `Подсистема.Имя`), `subsystem_path` = `Подсистема.ПолноеИмя`. Вложенный пример: `Подсистема.Продажи.Подсистема.РозничныеПродажи`.
9. **`config_id` из `СвойстваКонфигурации.Синоним`.** Версия парсится regex, дата — из имени файла.
10. **MCP SDK v2 (mcp 2.3.0):** `transport_security` передаётся в `run()`, а **не** в `MCPServer(...)`. Если передать в конструктор — BDS получит 403 при подключении.
11. **Для изменения маппинга существующих строк — чистая пересборка.** `ingest.py` существующие `full_name` пропускает и не обновляет; добавление новых подсистем дописывается, исправление старых полей — через новую БД и подмену.
12. **`attribute_types` не имеет прямого FK на `objects` — это нормально.** Связь: `attribute_types.attribute_id → attributes.id → objects.id`.

## Окружение

- Windows, PowerShell 5.1
- Python 3.14, `mcp 2.3.0` (SDK v2), `ijson 3.6.0`, `jsonschema`, `pytest`
- MCP-сервер KB: `.venv\Scripts\python.exe tools/mcp_server.py --no-dns-protection` (порт 8000)
- MCP-сервер STRUCT: `.venv\Scripts\python.exe projects/unf30-kb/struct/struct_mcp.py --db projects/unf30-kb/struct/data/struct.db --port 8001`
- В BDS подключены оба: `unf30-kb` (8000) и `struct-unf30` (8001)

**Важно про PowerShell:** красный текст в консоли от `py`/Python (`CategoryInfo: NotSpecified`, `RemoteException`) часто является обёрткой над stderr. Смотри на фактическую последнюю строку результата. Для русского вывода использовать UTF-8: `chcp 65001`, `[Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)`, `$env:PYTHONIOENCODING = "utf-8"`, `python -X utf8`.

## Правила общения

- Не использовать старые BDS-инструменты для записи файлов без просьбы.
- Не выдумывать имена объектов 1С. Если чего-то нет в фактах — писать «нет данных».
- Объяснять сложные ИИ-термины через аналогии из 1С, базовые понятия 1С — не объяснять.
- Отвечать по-русски.
- Не пересматривать ключевые решения без причины (пункты 1–12 выше).
