## Что за проект

ИИ-база знаний (RAG) по конфигурации 1С **УНФ 3.0**. Пользователь —
внедренец с 25-летним опытом. Цель: давать проверяемые ответы, не галлюцинировать.

**Главный вывод:** поведение нельзя гарантировать промптом. Правильность
обеспечивается **кодом и структурой данных**.

**Историческая справка:** это новый проект. Старый (RAG только по ручным
KB-карточкам, 43 шт.) признан неудачным и тупиковым. В новом проекте
`kb/unf30` — лишь один из слоёв, а не единственный источник истины.

## Ключевые решения (не пересматривать без причины)

1. **STRUCT → SQLite**, не векторную БД. Точный поиск по именам надёжнее семантики.
2. **`Раскрытие` из выгрузки не храним** — граф из `Типы` + `СвойстваОбъекта`.
3. **`СвойстваОбъекта` — в колонки + JSON.** Без `register_kind` модель путает регистры.
4. **ID фактов стабильные:** `obj:Документ.ЗаказПокупателя`, `attr:…`, `move:…`, `link:…`.
5. **Лимит 10–15 КБ на ответ MCP-инструмента.** Большие массивы обрезаются с `truncated`.
6. **Валидатор имён — код.** Все `ПолноеИмя` проверяются по `objects.full_name`.
7. **`ijson`, не `json.load`.** Файлы полной выгрузки 10–50 МБ.
8. **Подсистема — измерение в `objects`** (`subsystem`, `subsystem_path`). Читается автоматически из JSON, не через CLI-параметр. При следующей выгрузке («Закупки») проставится сама.
9. **`config_id` из `СвойстваКонфигурации.Синоним`.** Ключей `Конфигурация`/`Версия`/`ДатаВыгрузки` в JSON экспортёра **нет**. Версия парсится из строки «Управление нашей фирмой, редакция 3.0» → `3.0`. Дата — из имени файла `_YYYYMMDD_HHMMSS`.
10. **`iter_documents()` — основной итератор.** Отдаёт `(header, obj)`. `iter_objects`/`iter_header` — устаревшие обёртки, оставлены для совместимости.
11. **Поиск файлов через `rglob`**, не `glob` — на случай вложенных папок подсистем.

## Окружение

- Windows, PowerShell 5.1
- Python 3.14 (`py`)
- `ijson 3.6.0`, `jsonschema 4.26.0`, `pytest 9.2.0`
- MCP-сервер: `py tools/mcp_server.py --no-dns-protection` в `.venv`,
  адрес `127.0.0.1:8000/mcp`
- `unzip-watcher.ps1` — распаковщик, кладёт архив в `C:\ai_workSpaceGitHub`
  с сохранением структуры папок. Архив должен содержать корень `ai_workspace/`

**Важно про PowerShell:** красный текст в консоли от `py` (например,
`CategoryInfo: NotSpecified`, `RemoteException`) — это **не ошибка**.
PowerShell так показывает вывод Python в stderr. Смотри на последнюю строку
(`Готово: вставлено …` или `OK: survey.json …`) — она и есть результат.
