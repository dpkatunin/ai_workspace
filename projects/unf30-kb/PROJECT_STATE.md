Живой документ. Обновлять при закрытии этапов. Служит для переезда между чатами.

**Репозиторий:** github.com/dpkatunin/ai_workspace
**Ветка:** main

## Контекст

Пользователь — внедренец 1С с 25-летним стажем. Мы строим ИИ-базу знаний (RAG)
для быстрого поиска ответов по конфигурации УНФ 3.0. Цель — давать проверяемые
ответы, не галлюцинировать, строго следовать фактам.

**Главный вывод после провала прошлой версии:** поведение нельзя гарантировать
промптом. Правильность должна обеспечиваться кодом и структурой данных.

## Ключевые решения (с обоснованием)

| Решение | Обоснование |
|---|---|
| STRUCT — в SQLite, не в векторной БД | Точный поиск по именам и синонимам — надёжнее семантики. Эмбеддинги — для HELP и KB |
| `Раскрытие` из выгрузки не храним | Дублирование. Граф собираем из `Типы` + `СвойстваОбъекта` |
| `СвойстваОбъекта` — в колонки + JSON | Без `register_kind` модель галлюцинирует `.ОстаткиИОбороты()` |
| ID фактов стабильные (`obj:…`, `attr:…`) | Модель ссылается на ID. Утверждение без ID — дефект |
| Лимит 10–15 КБ на ответ MCP | 1 полный объект в JSON = 30–50 КБ = половина контекста |
| Валидатор имён — код | Промпт не гарантирует. Только проверка по словарю |
| `json.load` не используем, `ijson` — да | Файлы полной выгрузки 10–50 МБ. Стримим, не грузим в память |
| `subsystem` — измерение в objects | Читается из JSON, не из CLI. При заливке «Закупок» проставится сама |
| `config_id` из `СвойстваКонфигурации.Синоним` | Ключей `Конфигурация`/`Версия`/`ДатаВыгрузки` в JSON нет. Версия — regex, дата — из имени файла |
| `iter_documents()` — основной итератор | Отдаёт `(header, obj)`. `iter_objects`/`iter_header` — устаревшие обёртки |
| Поиск файлов — `rglob`, не `glob` | На случай вложенных папок подсистем |
| `struct_mcp.py` — автодетект колонок через PRAGMA | Устойчивость к минорным расхождениям схемы без падения по KeyError |
| `predefined: []` — заглушка в контракте | Экспортёр пока не отдаёт. При смене экспортёра контракт ответа не меняется |
| **MCP SDK v2:** `transport_security` в `run()` | В v2.3.0 `MCPServer.__init__` его не принимает. Передача в `run()` — как в KB-сервере. Иначе 403 |
| **Имена объектов УНФ отличаются от УТ 11** | `ЗаказПокупателя` (не `ЗаказКлиента`), `Номенклатура` (не `Товары`). Валидатор это ловит |
| **ingest.py пропускает существующие full_name** | Идемпотентность = пропуск, НЕ update. Изменение маппинга полей → чистая пересборка; добавление новых подсистем → обычная дозаливка |
| **HELP: статья = один файл `Help/ru.html`** | Файл и есть естественный чанк; относительный путь — стабильный ID (`INSERT OR REPLACE` по path) |
| **HELP: фильтр по каталогу `Help` в пути** | `Templates/.../Ext/Template/ru.html` — тексты макетов, не справка; без фильтра засоряют базу |
| **HELP: уровень `Ext/` в путях выгрузки** | Реальные пути `Documents/X/Ext/Help/ru.html`; классификатор пропускает `Ext` и `Help`, разбирает остальную цепочку |
| **HELP: object_full_name из пути файла** | Папки выгрузки (`Documents`, `Catalogs`, …) маппятся в русские виды; вложенные подсистемы → `Подсистема.А.Подсистема.Б` |
| **help_mcp.py = копия каркаса struct_mcp.py** | Один проверенный паттерн SDK v2, меняются только запросы и порт (8002) |
| **Kimi Code: stdio-запуск struct/help** | Kimi Code сам стартует python-процессы из `.kimi-code/mcp.json`; окна PowerShell не нужны. Проектный mcp.json требует Trust + новой сессии |

## Известные ограничения экспортёра (Romandredan/1c-metadata-json-exporter)

| Что | Статус | Компенсация |
|---|---|---|
| `predefined` (предопределённые) | не выгружается | `predefined: []` в контракте как заглушка |
| `ОпределяемыйТип` — состав | не выгружается | реквизиты с типом определяемого разложены на конкретные |
| `ЖурналДокументов` — состав | не выгружается | — |
| `СвойстваКонфигурации` — только `Синоним`, `Поставщик`, режимы | нет `Версия`, `ДатаВыгрузки` | версия — regex, дата — из имени файла |

## Известные проблемы / TODO

- FTS5 (unicode61) не знает русской морфологии: поиск «резервировать» не найдёт «зарезервировать». Кандидат на доработку HELP-слоя.
- `survey.py` читает файлы дважды (заголовок + объекты). На 13 МБ — секунды.
- `ingest.py` не валидирует вход по `schema/metadata-output.schema.json` экспортёра.
- FTS5 на Windows-Python 3.14 обычно встроен, но нужен fallback (см. `build_fts`).
- В `struct_mcp.py` есть автодетект колонок; после стабилизации схемы можно заменить на явные имена для скорости (не критично — PRAGMA-запрос кэшируется).
