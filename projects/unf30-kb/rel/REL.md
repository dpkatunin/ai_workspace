# REL-слой: журнал релизов (этап 3, 2026-11-08)

REL закрывает то, чего не закрывают STRUCT и HELP: **поведение объекта
изменилось, а имя осталось**. STRUCT снимает метаданные, HELP — справку,
но ни один из них не говорит «в версии 3.0.14.159 у чека коррекции появилась
облачная ККТ». Это фиксирует журнал релизов.

## Источник

Публичная страница ITS (авторизация не нужна):

    https://its.1c.ru/db/content/updinfo/src/smallbusiness/<версия>/index.htm

Варианты входа:
- сохранить страницу в браузере (Ctrl+S → «Веб-страница, HTML») и дать файл
  через `--html`;
- или сразу `--url` со ссылкой — скрипт скачает сам.

PDF-распечатки НЕ принимать: кириллица в них портится кодировкой шрифтов,
восстановлению не подлежит. Если прислали PDF — источник всё равно HTML
(ссылка есть в колонтитуле PDF), взять оттуда.

## Хранилище: rel.db (SQLite)

    releases        — версия, заголовок, источник, дата загрузки (UNIQUE по версии)
    entries         — разделы: path («Розничные продажи/Чек коррекции…»), title, body
    entry_objects   — привязки разделов к objects.full_name (by, n_words, context)

Путь по умолчанию: `projects/unf30-kb/rel/data/rel.db`.

## Правила

1. **Накопительный журнал, не снимок.** Каждая новая версия добавляется
   поверх. Повторная загрузка той же версии заменяет её записи (поставщик
   может править страницу).
2. **При расхождении REL и STRUCT истина — STRUCT.** REL описывает поведение
   текстом, STRUCT — фактический состав конфигурации.
3. **Линковка — предложение, не факт.** Привязки строятся по совпадению
   синонимов/имён (механизм общий с kb_anchors_propose). Раздел без привязок
   помечается ⚪ в отчёте — это нормально: не всякое изменение касается
   именованного объекта (драйверы, законодательство, профили доступа).
4. **CLI-first.** MCP-инструменты поверх rel.db — после того, как журнал
   окажется полезен в работе (не раньше).

## Запуск (из projects/unf30-kb/rel)

    .venv\Scripts\python.exe -X utf8 rel_ingest.py ^
        --url "https://its.1c.ru/db/content/updinfo/src/smallbusiness/3.0.14.159/index.htm" ^
        --md ingest_3.0.14.159.md

Ожидаемый результат: версия определена из заголовка, разделы с иерархией,
рядом с каждым разделом привязанные объекты с контекстом, ⚪ у разделов
без привязок.
