# MCP-инструменты слоя STRUCT

Все инструменты возвращают JSON:

```json
{
  "facts": [
    {
      "fact_id": "obj:Документ.ЗаказКлиента",
      "type": "object",
      "source": "STRUCT",
      "source_file": "Документ.ЗаказКлиента.json",
      "data": { ... }
    }
  ],
  "not_found": [],
  "meta": { "truncated": false, "total": 1 }
}
```

Если поле `data` было обрезано из-за лимита — в `meta` появится `truncated: true`
и `original_size_bytes`.

## Лимиты

**Один вызов = не больше 10–15 КБ.** Это правило архитектурное.

Реализация:

- Массивы > 20 элементов → первые 20 + `truncated: true` + `total`.
- `attribute_types` в одном реквизите > 20 → первые 20 + `total`.
- Все `data` в одном ответе ≤ 15 КБ (проверка через `len(json.dumps(...))`).

## Инструменты

| Инструмент | Параметры | Возвращает | Лимит |
|---|---|---|---|
| `search_objects(query, kind?, limit=20)` | FTS по full_name, name, synonym, comment | `obj:*` с snippet | limit ≤ 20 |
| `get_object(full_name)` | ПолноеИмя | `obj:*` + реквизиты + ТЧ + движения + значения перечислений + предопределённые | если реквизитов > 30 — обрезать, вернуть `total_attributes` |
| `get_object_links(full_name, link_type?)` | link_type ∈ {owner, registrator, based_on, movement} | `link:*` | limit 50 |
| `get_register_writers(register_full_name)` | ПолноеИмя регистра | `link:* registrator` | limit 100 |
| `get_document_movements(document_full_name)` | ПолноеИмя документа | `move:*` | limit 50 |
| `get_attribute(object_full_name, attribute_name, types_limit=20)` | + `types_limit` | `attr:*` + `attribute_types` (≤20) | `types_limit` ≤ 20, если больше — `truncated` |
| `get_enum_values(enum_full_name)` | ПолноеИмя перечисления | `enum:*` | limit 200 |
| `get_config_info()` | — | `cfg:*` (name, version, dump_date) | — |
| `validate_names(full_names[])` | Массив `ПолноеИмя` | `{ known: [...], unknown: [...] }` | без лимита (это валидатор) |

## Примеры

### `get_object("Документ.ЗаказКлиента")` → фрагмент

```
{
  "facts": [
    {
      "fact_id": "obj:Документ.ЗаказКлиента",
      "type": "object",
      "source": "STRUCT",
      "data": {
        "kind": "Документ",
        "synonym": "Заказ клиента",
        "properties": {
          "Проведение": "Разрешить",
          "ВводитсяНаОсновании": ["Документ.КоммерческоеПредложениеКлиенту"]
        }
      }
    },
    {
      "fact_id": "attr:Документ.ЗаказКлиента.Контрагент",
      "type": "attribute",
      "data": {
        "name": "Контрагент",
        "types": ["Справочник.Контрагенты"],
        "check_fill": "Выдавать ошибку"
      }
    }
  ],
  "meta": {
    "truncated": true,
    "total_attributes": 87,
    "returned_attributes": 30
  }
}
```

### `validate_names` — механизм против галлюцинаций

```
{
  "facts": [
    {
      "type": "validation",
      "data": {
        "known": ["Документ.ЗаказКлиента", "Справочник.Контрагенты"],
        "unknown": ["Документ.РеализацияТоваров", "Справочник.Товары"]
      }
    }
  ]
}
```

Если `unknown` непуст — пост-процессор **блокирует** ответ модели
(или добавляет в ответ пометку «следующие имена не найдены в конфигурации: …»).

## Почему не «просто выдать полный объект»

Полный объект `Документ.ЗаказКлиента` в JSON — 30–50 КБ. Это 15–25 тыс. токенов
на один вызов. При 3–5 вызовах на ответ уходит 100 тыс. токенов, а у модели
контекст 128–200 тыс. Один вопрос — половина контекста.

Лимит 10–15 КБ на вызов — это не «оптимизация», а **условие работы**.

## Ключевые решения (с обоснованием)

| Решение | Обоснование |
|---|---|
| STRUCT — в SQLite, не в векторной БД | Точный поиск по именам и синонимам — надёжнее семантики. Эмбеддинги — для HELP и KB |
| `Раскрытие` из выгрузки не храним | Дублирование. Граф собираем из `Типы` + `СвойстваОбъекта` |
| `СвойстваОбъекта` — в колонки + JSON | Без `register_kind` модель галлюцинирует `.ОстаткиИОбороты()` |
| ID фактов стабильные (`obj:…`, `attr:…`) | Модель ссылается на ID. Утверждение без ID — дефект |
| Лимит 10–15 КБ на ответ MCP | 1 полный объект в JSON = 30–50 КБ = половина контекста |
| Валидатор имён — код | Промпт не гарантирует. Только проверка по словарю |
| `json.load` не используем, `ijson` — да | Файлы полной выгрузки 10–50 МБ. Стримим, не грузим в память |
